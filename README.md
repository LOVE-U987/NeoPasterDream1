## 📖 这是什么？

**新帕斯特之梦（NeoPasterDream）** 是经典模组 **帕斯特之梦（PasterDream）** 在 Minecraft **1.21.1 NeoForge** 上的**精神续作**。

原版模组（1.20.1 Forge）作者精美的纹理、模型和视觉设计——我们全部保留。但**所有代码从零重写**，完全不使用 MCreator 生成的代码。

> 🐦‍⬛ **授权问题**：我已获得原作者授权，这里的所有活动均接受原作者监督

***

## 🔥 这不仅仅是移植。这是**重生**。

原版模组使用 MCreator 构建，这在代码结构、性能和扩展性上都有所限制。新帕斯特之梦使用 **NeoForge 原生 API + DeferredRegister + GeckoLib** 重新实现了一切，为模组带来了更好的性能和更大的扩展空间。

**原版主路径注册与自动化行为抽测已闭环**（CORE 近次 140/0，含饰品 curios×53；全量行为 250+）。它仍会成长——但首先，你可以完整游玩原作者设计的染梦/影灯/风旅主线。

## 🌌 故事背景

> **你将不再只是一个普通的旅者，而是一位「寻梦者」。**

帕斯特之梦是一个拥有**剧情故事主线的冒险模组**。你将在某种机缘巧合下发现、并去探索这个不同寻常的**梦境**。

在探索的路上，你会发现许多"前辈"寻梦者们留下的**寻梦者笔记**与他/她们的个人传记，并以此学习**知识**，逐渐获得可以控制并利用**梦境的能力**。

你将在穿越种种**不同梦境**的时空中，探索截然不同、可能是**美梦**与**噩梦**的奇妙世界：

- 寻找遗迹里埋藏的**宝藏**
- 制作拥有**特殊功能**的武器装备武装自己
- 去追寻这个梦境最源头的秘密——即使前辈们早已不见踪影

因为此时的你，早已无法回头。

这将是一场精神的卓绝长征——为了你自己，或者是以往寻梦者之中的某一人。

## 🎮 核心玩法

### 🌱 开端：现实与梦境的交界

在探索世界的时光中，你能发现一些突兀于现实之外的**自然奇观**。

为了满足你的好奇心，去发现并探索它们，并在此后睡眠的梦境中与"那个地方"连结共鸣——梦境的旅程，从你闭上眼睛的那一刻开始。

### 🌍 梦境世界探索 —— 四大维度

超越现实的全新维度，每一个都是截然不同的梦境：

| 维度 | 主题 | 特色 |
| :--- | :--- | :--- |
| **染梦之境** | 色彩斑斓的美梦 | 自定义 biome source · 噪声地形 · 极光天空 · 深海/海岸/密林/雪原等丰富群系 · 迷梦冶梦莲多方块 · 狐狸雕像仪式 |
| **灯影之下（影灯世界）** | 沉眠古城的噩梦 | 暗影群系 · 地牢与结构 · 暮影之笼事件 · 真影之床抉择 · 影之抉择天赋 · 亚伦柯斯的愤怒 |
| **风之旅途** | 天空之上的新梦 | 风泊木生态 · 风向规则（Pr0–2）· 破风幕 · 纸飞机 · 风骑士祭坛与 Boss · 水色湖常驻 |
| **亚伦柯斯竞技场** | 终焉之战 | 亚伦柯斯 Boss 战 · 左右手机制 · Boss 血条 · 史诗战场 |

各梦境世界均可通过裂隙、传送水晶、梦境物品等**正式入口**进入，不改写主世界生成。

### 🏛️ 遗迹探索

寻找过往寻梦者前辈的历史留痕，或者探寻未知的自然奇观，发掘埋藏的宝藏和新的知识笔记。

- **染梦遗迹群**：RuinsAPI 驱动的 41 组遗迹 · 教堂 0–10 全量
- **结构触发方块 0–23**：放置即激活结构生成（设计如此，自毁机制）
- **强征传送塔 · 染梦列车 · 世界树 · 地牢** 等特色结构

### 📜 剧情与故事

游历世界，寻找前辈们的笔记或者由自己撰写。

在这些笔记中获得知识，让你可以制作或使用新的物品或祭坛。还有一些是过往寻梦者的**日记**——写下这些，为了证明自己来到过此地，也为了留给他们的后来之人。

- **寻梦者笔记 0–14** · **卡勒卡牌 0–9**（含全屏特效与"熔金坠落"）
- **天赋抉择**：光与影，二选一的宿命（ShadowSelectEndMenu）
- **纪念物 01–11**：承载记忆与增益
- **帕斯特指南**（Patchouli 图鉴）：梦境规则的随身手册
- **62 项成就**，覆盖全剧情链

### ⚔️ 战斗扩充

相对于传统的武器装备，每件特殊装备都会有他们的特殊**被动**、**战技**以及**套装效果**等。

- **瞬身术**：内置"闪避"技能，魂系战斗的位移核心
- **法术系统**：五系法术投射物 + 法杖投射物族 + 治疗/狂暴立场
- **饰品系统**：Curios 深度集成——戒指、手环、护符、纸飞机等 50+ 饰品，属性/增益严格对齐原版数值
- **自定义属性**：skill / teleportation / san / magic / healing 等 10 项属性体系
- **San 理智系统**：目击不可名状之物会让理智滑落（含 HUD 与抖动效果）
- **融梦能量系统**：能量 HUD + 能量戒指 + 法杖耗能
- **武器工坊**：铁砧/锻炉/冷却盆/磨石四件套 + 三套 GUI，锻造你的专属神兵

## ✨ 重生带来的技术优化

| 方面 | 原版（MCreator） | 新帕斯特之梦 |
| :--- | :--- | :--- |
| **框架** | 1.20.1 Forge + MCreator 生成代码 | **1.21.1 NeoForge 原生 API** |
| **注册体系** | 零散、不可控 | **DeferredRegister + DataGen** 全量数据驱动 |

| **附加能力** | — | **San 理智 / 融梦能量 / 自定义属性** 等属性系统化实现 |

## 📦 安装与打包

本仓库多子模块，**发布给玩家时只装一个 jar**（再加下方运行时依赖）：

| 产物 | 说明 |
| :--- | :--- |
| `build/dist/pasterdream-<version>.jar` | **本模组**可安装包；Jar-in-Jar **内嵌** `PasterDreamAPI` + `PasterDreamSanity` + `PasterDreamMeltDream` + `PasterDreamSpells`（由 `enable*=true` 控制） |
| 各附属 / API 独立 jar | 仅开发或模块化发行用；**已内嵌时不要**再丢进 `mods/`（会重复加载） |

### 玩家 / 整合包需一并安装的依赖

本模组**不**把第三方 jar 打进发布包（标准 soft-dep 方式）。`neoforge.mods.toml`：

| modId | 关系 | 建议版本（与开发一致） |
| :--- | :-: | :--- |
| `geckolib` | **required** | 4.8.4（1.21.1 NeoForge） |
| `curios` | **required** | 9.5.1+1.21.1 |
| `playeranimator` | optional | 2.0.4+1.21.1 |
| `jei` | optional | 开发期 localRuntime，玩家自选 |
| `patchouli` | optional | 帕斯特指南图鉴的查看前置 |
| `kubejs` | optional | 娃娃（Doll）注册脚本联动 |

### 开发者依赖（Maven，不再使用 `libs/*.jar`）

版本集中在根目录 [`gradle.properties`](gradle.properties)：`geckolib_version` / `curios_version` / `player_anim_version` / `jei_version`。

```groovy
// :PasterDream — 节选
implementation "software.bernie.geckolib:geckolib-neoforge-${minecraft_version}:${geckolib_version}"
implementation "top.theillusivec4.curios:curios-neoforge:${curios_version}"
implementation "dev.kosmx.player-anim:player-animation-lib-forge:${player_anim_version}"
```

仓库：GeckoLib Cloudsmith · TheIllusiveC4 · KosmX · BlameJared（JEI）。  
`libs/` 仅作**对照源码**（如 `FixPasterDream-main`），**不要**再放依赖 jar。

```bash
# 仓库根；需要 Java 21（首次解析依赖需联网；之后可用 --offline）
JAVA_HOME=/usr/lib/jvm/java-21-openjdk sh gradlew packageMod
# 或 :PasterDream:packageMod ；assemble / build 也会触发 packageMod
```

拷贝 `build/dist/pasterdream-*.jar` 与 GeckoLib / Curios（及可选 Player Animator）到游戏 `mods/` 即可（版本号见 `gradle.properties` 的 `mod_version`）。

## ⚠️ 注意事项与兼容性

| 事项 | 说明 |
| :--- | :--- |
| **OptiFine（高清修复）** | 与模组**不兼容**（延续原版警告）。推荐使用 **Embeddium + Oculus** 获得光影与优化体验 |
| **MCreator 无关** | 本模组为纯手写 NeoForge 原生代码，不依赖 MCreator 运行时 |
| **存档安全** | 染梦等维度通过裂隙/物品进入，不改写主世界生成；未来更新尽量向后兼容 |
| **多人联机** | **完全兼容**多人服务器 |
| **图鉴前置** | 阅读《帕斯特指南》需另行安装 Patchouli |
| **脚本联动** | 娃娃（Doll）系统提供 KubeJS 注册事件，方便整合包作者自定义 |
| **开发阶段** | 移植主线已闭环，但仍有手感打磨与扩展内容进行中；欢迎反馈问题与建议 |
| **反馈渠道** | GitHub Issues：[`LOVE-U987/NeoPasterDream1`](https://github.com/LOVE-U987/NeoPasterDream1/issues) |
