# 注册指南

> 本文档详解 PasterDream 的注册系统,包括方块、物品、实体、效果等的注册方法。

---

## 注册系统总览

PasterDream 使用 NeoForge 的 `DeferredRegister` 进行注册,通过 API 模块提供 Builder 模式简化注册流程。

### 注册入口

```java
// PasterDreamAPI.java
public static void registerAll(IEventBus modEventBus) {
    BlockAPI.REGISTRY.register(modEventBus);
    EntityAPI.REGISTRY.register(modEventBus);
    ItemAPI.REGISTRY.register(modEventBus);
    ParticleAPI.REGISTRY.register(modEventBus);
    MobEffectAPI.REGISTRY.register(modEventBus);
    // ... 13 个 DeferredRegister
}
```

## 方块注册

### 模式一: SimpleBlockBuilder

适用于简单方块,无需特殊属性:

```java
BlockResult<Block> result = BlockAPI.createBlock("my_block")
    .properties(BlockBehaviour.Properties.of()
        .mapColor(MapColor.STONE)
        .requiresCorrectToolForDrops()
        .strength(3.0f, 3.0f))
    .build();

// 注册方块物品
BlockAPI.registerBlockItem(result, CreativeModeTabs.BUILDING_BLOCKS);
```

### 模式二: VariantSetBuilder

适用于有变体的方块 (如不同朝向):

```java
BlockResult<Block> result = BlockAPI.createBlock("my_directional_block")
    .properties(BlockBehaviour.Properties.of()
        .mapColor(MapColor.STONE))
    .variantSet(VariantSetBuilder.builder()
        .horizontal(BlockStateProperties.HORIZONTAL_FACING)
        .model("my_directional_block")
        .build())
    .build();
```

### 模式三: BatchBlockBuilder

适用于批量注册相似方块:

```java
BatchBlockBuilder batch = BlockAPI.createBatch("my_block")
    .properties(BlockBehaviour.Properties.of()
        .mapColor(MapColor.STONE)
        .strength(2.0f));

batch.add("my_block_1", b -> b.build());
batch.add("my_block_2", b -> b.build());
batch.add("my_block_3", b -> b.build());

batch.registerAll();
```

### 手动注册

适用于需要自定义逻辑的方块:

```java
public class PDBlocks {
    public static final DeferredBlock<Block> MY_BLOCK = 
        BlockAPI.REGISTRY.register("my_block", () -> new MyBlock(
            BlockBehaviour.Properties.of()
                .mapColor(MapColor.STONE)
                .strength(3.0f)));
}
```

## 物品注册

### SimpleItemBuilder

适用于简单物品:

```java
ItemResult<Item> result = ItemAPI.createItem("my_item")
    .properties(new Item.Properties()
        .stacksTo(64))
    .build();

// 注册到创造标签
ItemAPI.registerToTab(result, CreativeModeTabs.TOOLS_AND_UTILITIES);
```

### FoodItemBuilder

适用于食物物品:

```java
ItemResult<Item> result = ItemAPI.createFood("my_food")
    .properties(new Item.Properties()
        .stacksTo(64)
        .nutrition(3)
        .saturationModifier(0.8f))
    .effect(() -> new MobEffectInstance(MobEffects.REGENERATION, 200, 0), 1.0f)
    .build();
```

### ToolItemBuilder

适用于工具物品:

```java
ItemResult<Item> result = ItemAPI.createTool("my_tool")
    .properties(new Item.Properties()
        .stacksTo(1)
        .durability(1000))
    .tool(Tier.IRON, 6, -2.4f)
    .build();
```

### CurioItemBuilder

适用于饰品物品:

```java
ItemResult<Item> result = ItemAPI.createCurio("my_ring")
    .properties(new Item.Properties()
        .stacksTo(1))
    .slot(CurioSlot.RING)
    .attribute(Attributes.MAX_HEALTH, 2.0, AttributeModifier.Operation.ADD_VALUE)
    .build();
```

### 手动注册

适用于需要自定义逻辑的物品:

```java
public class PDItems {
    public static final DeferredItem<Item> MY_ITEM = 
        PDItems.ITEMS.register("my_item", () -> new MyItem(
            new Item.Properties()
                .stacksTo(64)));
}
```

## 注册顺序

1. **API 模块注册**: `PasterDreamAPI.registerAll(modEventBus)`
2. **触发类加载**: 填充 DeferredRegister
3. **显式注册**: `PDItems.ITEMS.register(modEventBus)` 等
4. **事件监听**: 注册事件处理器

## 常见问题

### Q: 为什么注册名要用 snake_case?

NeoForge 的注册系统使用资源定位器 (ResourceLocation),格式为 `namespace:path`。为了兼容性和一致性,注册名使用全小写的 snake_case。

### Q: 如何注册到创造标签?

```java
// 方块
BlockAPI.registerBlockItem(result, CreativeModeTabs.BUILDING_BLOCKS);

// 物品
ItemAPI.registerToTab(result, CreativeModeTabs.TOOLS_AND_UTILITIES);
```

### Q: 如何注册自定义属性?

```java
// 定义属性
public static final Holder<Attribute> MY_ATTRIBUTE = 
    AttributeRegistry.register("my_attribute", new RangedAttribute("my_attribute", 0.0, 0.0, 1024.0));

// 注册到实体
EntityResult<MyEntity> result = EntityAPI.createEntity("my_entity")
    .category(MobCategory.MONSTER)
    .size(1.0f, 2.0f)
    .entityClass(MyEntity.class)
    .attributes(MyEntity::createAttributes)
    .attribute(MY_ATTRIBUTE, 10.0)
    .build();
```
