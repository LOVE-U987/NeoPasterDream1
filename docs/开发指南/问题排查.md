> 本文档列出 PasterDream 开发中常见的错误和解决方案。

## 方块相关问题

### 问题 1: 方块无掉落物

**症状**: 破坏方块后没有掉落物。

**可能原因**:
1. BlockItem 未注册
2. `getDrops()` 被覆写但返回空
3. 战利品表 JSON 格式错误

**解决方案**:

```java
// 1. 检查 BlockItem 是否注册
BlockAPI.registerBlockItem(myBlockResult, CreativeModeTabs.BUILDING_BLOCKS);

// 2. 检查 getDrops() 方法
@Override
public List<ItemStack> getDrops(BlockState state, LootParams.Builder builder) {
    // 确保返回正确的掉落物
    return List.of(new ItemStack(this));
}
```

**战利品表 JSON 格式 (1.21.1)**:

```json
{
    "type": "minecraft:block",
    "pools": [
        {
            "rolls": 1.0,
            "entries": [
                {
                    "type": "minecraft:item",
                    "name": "pasterdream:my_block"
                }
            ],
            "conditions": [
                {
                    "condition": "minecraft:match_tool",
                    "predicate": {
                        "predicates": {
                            "minecraft:enchantments": [
                                {
                                    "enchantments": "minecraft:silk_touch",
                                    "levels": {"min": 1}
                                }
                            ]
                        }
                    }
                }
            ]
        }
    ]
}
```

**注意**: 1.21.1 的 `match_tool` 格式与 1.20 不同,需要 `predicates` 包装。

### 问题 3: 方块实体不渲染

**症状**: 方块实体 (BE) 不显示 GeckoLib 模型。

**可能原因**:
1. 渲染器未注册
2. 模型路径错误
3. 动画文件路径错误

**解决方案**:

```java
// 1. 注册渲染器
@EventBusSubscriber(modid = MOD_ID, value = Dist.CLIENT)
public class ClientSetup {
    @SubscribeEvent
    public static void onEntityRenderers(EntityRenderersEvent.RegisterRenderers event) {
        event.registerBlockEntityRenderer(PDBlockEntities.MY_BE, MyBlockEntityRenderer::new);
    }
}

// 2. 检查渲染器代码
public class MyBlockEntityRenderer extends GeoBlockRenderer<MyBlockEntity> {
    public MyBlockEntityRenderer(EntityRendererProvider.Context context) {
        super(context, new DefaultedBlockGeoModel<>(ResourceLocation.fromNamespaceAndPath(MOD_ID, "my_block")));
        // 确保路径正确: geo/block/my_block.geo.json
    }
}
```

## 实体相关问题

### 问题 1: 实体不显示

**症状**: 实体在游戏中不可见。

**可能原因**:
1. 渲染器未注册
2. 模型路径错误
3. 纹理路径错误

**解决方案**:

```java
// 1. 注册渲染器
@EventBusSubscriber(modid = MOD_ID, value = Dist.CLIENT)
public class ClientSetup {
    @SubscribeEvent
    public static void onEntityRenderers(EntityRenderersEvent.RegisterRenderers event) {
        event.registerEntityRenderer(PDEntities.MY_ENTITY, MyEntityRenderer::new);
    }
}

// 2. 检查渲染器代码
public class MyEntityRenderer extends GeoEntityRenderer<MyEntity> {
    public MyEntityRenderer(EntityRendererProvider.Context context) {
        super(context, new MyEntityModel());
        // 确保模型路径正确: geo/entity/my_entity.geo.json
    }
    
    @Override
    public ResourceLocation getTextureLocation(MyEntity entity) {
        return ResourceLocation.fromNamespaceAndPath(MOD_ID, "textures/entity/my_entity.png");
    }
}
```

### 问题 2: 实体动画不播放

**症状**: 实体动画卡住或不播放。

**可能原因**:
1. 动画文件路径错误
2. 动画控制器未注册
3. 动画 JSON 格式错误

**解决方案**:

```java
// 1. 检查动画文件路径
// 应该是: animations/entity/my_entity.animation.json

// 2. 检查动画控制器
public class MyEntity extends GeckoLibMonsterEntity {
    private final ProcedureAnimationHandler animationHandler = new ProcedureAnimationHandler(this);
    
    @Override
    public void tick() {
        super.tick();
        animationHandler.tick();
    }
}
```

### 问题 3: 实体 AI 不工作

**症状**: 实体不执行 AI 行为。

**可能原因**:
1. AI Goal 未注册
2. AI Goal 优先级错误
3. 目标选择器错误

**解决方案**:

```java
@Override
protected void registerGoals() {
    this.goalSelector.addGoal(0, new FloatGoal(this));
    this.goalSelector.addGoal(1, new MeleeAttackGoal(this, 1.0, true));
    this.targetSelector.addGoal(1, new NearestAttackableTargetGoal<>(this, Player.class, true));
}
```

### 问题 2: 物品不能使用

**症状**: 物品右键无反应。

**可能原因**:
1. `use()` 方法未覆写
2. 事件未注册
3. 条件检查失败

**解决方案**:

```java
@Override
public InteractionResultHolder<ItemStack> use(Level level, Player player, InteractionHand hand) {
    ItemStack stack = player.getItemInHand(hand);
    
    // 检查条件
    if (!level.isClientSide) {
        // 执行逻辑
        return InteractionResultHolder.sidedSuccess(stack, level.isClientSide);
    }
    
    return InteractionResultHolder.pass(stack);
}
```

## 网络相关问题

### 问题 1: Payload 未注册

**症状**: 客户端收不到服务端数据。

**可能原因**:
1. Payload 未注册
2. Payload 类型不匹配
3. 处理器未注册

**解决方案**:

```java
// 1. 注册 Payload
public class PDNetwork {
    public static void register() {
        PayloadRegistrar registrar = INSTANCE.registrar("1");
        registrar.playToClient(MyPayload.TYPE, MyPayload.STREAM_CODEC, MyPayload::handle);
    }
}

// 2. 发送 Payload
public static void sendToPlayer(MyPayload payload, ServerPlayer player) {
    INSTANCE.send(PacketDistributor.PLAYER.with(() -> player), payload);
}
```

### 问题 2: 服务端加载客户端类

**症状**: 专用服务器启动失败,报 `ClassNotFoundException`。

**可能原因**:
1. 客户端类在服务端被引用
2. 未使用反射调用

**解决方案**:

```java
// 错误 ❌
import com.pasterdream.pasterdreammod.client.ClientHandler;
ClientHandler.doSomething();

// 正确 ✅
try {
    Class<?> clazz = Class.forName("com.pasterdream.pasterdreammod.client.ClientHandler");
    clazz.getMethod("doSomething").invoke(null);
} catch (Exception e) {
    // 安全处理
}
```

## 编译相关问题

### 问题 1: Java 版本不匹配

**症状**: 编译失败,提示 Java 版本错误。

**解决方案**:

```bash
# 检查 Java 版本
java -version

# 应该显示: openjdk version "21.x.x"

# 如果版本不对,设置 JAVA_HOME
set JAVA_HOME=C:\path\to\jdk-21
```

---

### 问题 2: 依赖缺失

**症状**: 编译失败,提示找不到依赖。

**解决方案**:

```bash
# 清理构建缓存
.\gradlew clean

# 重新编译
.\gradlew compileJava

# 如果还是失败,检查 gradle.properties 中的版本号
```

---

### 问题 3: Gradle 同步失败

**症状**: IDE 无法同步 Gradle 项目。

**解决方案**:

1. 删除 `.gradle/` 目录
2. 运行 `.\gradlew clean`
3. 重新打开 IDE
4. 等待 Gradle 同步完成

### 常见错误信息

| 错误信息 | 可能原因 |
|---------|---------|
| `ClassNotFoundException` | 客户端类在服务端加载 |
| `NullPointerException` | 空指针异常,检查对象初始化 |
| `IllegalArgumentException` | 参数错误,检查方法参数 |
| `RegistryObjectNotFound` | 注册对象未找到,检查注册顺序 |
