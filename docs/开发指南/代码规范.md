# 代码规范

> 本文档定义 PasterDream 项目的代码编写规范。

---

## 命名约定

| 类型 | 规范 | 示例 |
|------|------|------|
| **类** | PascalCase | `ShadowGolemEntity`, `DreamCauldronBlock` |
| **方法** | camelCase | `createAttributes`, `onPlayerTick` |
| **常量** | UPPER_SNAKE_CASE | `MOD_ID`, `MAX_SAN_VALUE` |
| **注册名** | snake_case | `shadow_golem`, `dream_cauldron` |
| **包名** | 全小写 | `com.pasterdream.pasterdreammod.api` |

### 特殊命名

| 类型 | 后缀 | 示例 |
|------|------|------|
| 实体类 | `Entity` | `ShadowGolemEntity` |
| 方块类 | `Block` | `DreamCauldronBlock` |
| 物品类 | `Item` 或无后缀 | `DreamWandItem`, `ShadowIngot` |
| 渲染器类 | `Renderer` | `ShadowGolemRenderer` |
| 模型类 | `Model` | `ShadowGolemModel` |
| 屏幕类 | `Screen` | `DreamCauldronScreen` |
| 菜单类 | `Menu` | `DreamCauldronMenu` |

## 格式规范

### 缩进

- **4 个空格**,禁止制表符 (Tab)
- 续行缩进 8 个空格

```java
// 正确 
public void myMethod() {
    if (condition) {
        doSomething();
    }
}

// 错误  (使用 Tab)
public void myMethod() {
	if (condition) {
		doSomething();
	}
}
```

### 大括号

K&R 风格 (右花括号在同一行):

```java
// 正确
if (condition) {
    doSomething();
} else {
    doOtherThing();
}

// 错误 (换行)
if (condition)
{
    doSomething();
}
```

### 换行符

- **LF (Unix 格式)**
- 不要使用 CRLF (Windows 格式)

### 行长度

- **推荐**: 120 字符
- **最大**: 150 字符

### 空格

- 运算符周围: `a = b + c`
- 逗号后: `method(a, b, c)`
- 冒号后: `case 1:`
- 关键字后: `if (condition)`, `for (int i = 0)`

## 编码规范

### 编码集

- **非 MD 文件**: 标准 ASCII 字符 + UTF-8 编码,禁止使用 Emoji
- **MD 文件**: UTF-8 编码,允许 Unicode 和 Emoji
- **代码注释**: 使用 UTF-8 字符 (如中文),但禁止使用 Emoji

### 注释语言

- **代码注释**: 推荐使用中文
- **提交信息**: 使用中文
- **文档**: 使用中文

### 导入顺序

1. 项目内部导入
2. 第三方库导入
3. Java 标准库导入

```java
// 项目内部
import com.pasterdream.pasterdreammod.api.block.BlockAPI;
import com.pasterdream.pasterdreammod.registry.PDBlocks;

// 第三方库
import net.minecraft.world.level.block.Block;
import net.neoforged.bus.api.SubscribeEvent;

// Java 标准库
import java.util.List;
import java.util.Map;
```

## 注册规范

### DeferredRegister 使用

所有注册必须使用 `DeferredRegister`:

```java
// 正确
public static final DeferredRegister<Block> REGISTRY = 
    DeferredRegister.create(Registries.BLOCK, MOD_ID);

// 错误 (直接注册)
Registry.register(Registries.BLOCK, "my_block", new MyBlock());
```

### 注册名规范

使用 snake_case,全小写:

```java
// 正确
BlockAPI.createBlock("shadow_golem")
BlockAPI.createBlock("dream_cauldron")

// 错误
BlockAPI.createBlock("ShadowGolem")
BlockAPI.createBlock("dreamCauldron")
```

## 实体开发规范

### 继承

- **怪物**: 继承 `GeckoLibMonsterEntity`
- **动物**: 继承 `GeckoLibAnimalEntity`
- **投射物**: 继承 `AbstractHurtingProjectile` 或自定义基类

### 属性注册

```java
public static AttributeSupplier.Builder createAttributes() {
    return Mob.createMobAttributes()
        .add(Attributes.MAX_HEALTH, 100.0)
        .add(Attributes.MOVEMENT_SPEED, 0.3)
        .add(Attributes.ATTACK_DAMAGE, 10.0);
}
```

### 动画系统

使用 `ProcedureAnimationHandler`:

```java
public class MyEntity extends GeckoLibMonsterEntity {
    private final ProcedureAnimationHandler animationHandler = new ProcedureAnimationHandler(this);
    
    @Override
    public void tick() {
        super.tick();
        animationHandler.tick();
    }
}
```

## 方块开发规范

### SelfDropBlock

适用于自身掉落的方块 (如矿石):

```java
public class MyOreBlock extends SelfDropBlock {
    public MyOreBlock(Properties properties) {
        super(properties);
    }
}
```

### BlockConfig

用于配置方块属性:

```java
BlockConfig config = BlockConfig.builder()
    .requiresCorrectToolForDrops()
    .strength(3.0f, 3.0f)
    .sound(SoundType.STONE)
    .build();
```

## 文件编码

### 换行符

- **所有文本文件**: LF (Unix 格式)
- **.bat 文件**: CRLF (Windows 格式)

### Python 脚本

```python
# 正确
with open(path, "w", encoding="utf-8", newline="\n") as f:
    f.write(content)

# 错误
with open(path, "w", encoding="utf-8") as f:
    f.write(content)
```

### PowerShell 脚本

```powershell
# 正确
$content = $content -replace "`r`n", "`n"
[System.IO.File]::WriteAllText($path, $content, [System.Text.UTF8Encoding]::new($false))

# 错误
Set-Content -Path $path -Value $content
```

## 常见错误

### 1. 使用 Tab 缩进

```java
// 错误
public void method() {
	if (condition) {
		doSomething();
	}
}

// 正确
public void method() {
    if (condition) {
        doSomething();
    }
}
```

### 2. 缺少注释

```java
// 错误
public float getDamage(DamageSource source, float amount) {
    return amount * 0.5f;
}

// 正确
/**
 * 计算减伤后的伤害值
 * 
 * @param source 伤害来源
 * @param amount 原始伤害
 * @return 减伤后的伤害
 */
public float getDamage(DamageSource source, float amount) {
    return amount * 0.5f;
}
```

### 3. 方法过长

```java
// 错误 (超过 50 行)
public void veryLongMethod() {
    // 100 行代码...
}

// 正确 (拆分为多个方法)
public void veryLongMethod() {
    step1();
    step2();
    step3();
}

private void step1() { /* ... */ }
private void step2() { /* ... */ }
private void step3() { /* ... */ }
```
