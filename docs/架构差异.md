# 架构差异（原版 vs 重写版）

> **类别**：参考 · 代码结构 / API / 实现策略  
> **日期**：2026-07-30（P0 + P1：FluidType / Menu / datagen / BGM 纯逻辑已迁 `PasterDreamAPI`）  
> **功能是否对等** → [`功能状态.md`](功能状态.md)（本文不回答「缺不缺」，只答「怎么做的」）

| | |
| :--- | :--- |
| **原版** | `libs/FixPasterDream-main/` · Forge 1.20.1 · MCreator |
| **重写版** | `PasterDream/` + `PasterDreamAPI/` · NeoForge 1.21.1 · 手写 |

---

## 1. 总体规模与组织

| 指标 | 原版 (1.20.1) | 重写版 (1.21.1) | 说明 |
|------|---------------|------------------|------|
| Java 文件数 | ~1814 | ~709 | 过程式 → 声明式 + 事件驱动 |
| JSON 文件数 | ~3145 | ~3720 | 高度数据驱动 |
| 主要逻辑 | `procedures/*`（~524） | `registry/*` + `block/*` + `item/*` + `event/*` | MCreator vs 手写 |
| 包名 | `net.pasterdream.*` | `com.pasterdream.pasterdreammod.*` | |
| Creative Tab | 1 | 10 分类 | 更细粒度 |

**核心转变**：过程式 procedure 堆叠 → 注册表 + 事件 + 数据驱动。

---

## 2. 核心 API 变更映射

| 原版（1.20.1 Forge） | 1.21 NeoForge | 移植处理 | 备注 |
|---------------------|---------------|----------|------|
| `Capability` + `IStorage` | **Attachment** | `PDAttachments` + `AttachmentType` | 机制重写 |
| `ArmorItem#onArmorTick` | **已移除** | `Item#inventoryTick` + `EquipmentSlot` | 强制变更 |
| `MCreator.queueServerWork` | `TickTask` **非真定时** | `api/util/ServerScheduler`（PQ + ServerTickEvent.Post；主模 `register(NeoForge.EVENT_BUS)`） | 避免轻载同 tick 塌缩；2026-07-29 上收 API |
| `SimpleChannel` + `IMessage` | **Payloads** | `PDNetwork` + record Payload（~5 vs 原 ~18） | 简化 |
| `RandomizableContainerBE` + `WorldlyContainer` | `BlockEntity` + `ItemStackHandler` | NeoForge 推荐模式 | |
| `DeferredWorkQueue` | 构造 / 事件注册 | `EventBusSubscriber` | |

## 3. 模块实现差异摘录

### 3.1 Wings

| 维度 | 原版 | 重写版 |
|------|------|--------|
| 飞行触发 | `onArmorTick` | `inventoryTick` + CHEST 槽 |
| 脱下延迟 | `queueServerWork` | `ServerScheduler` |
| 禁用 | 无 | `PDCommonConfig.BAN_ALL_THE_WINGS` |

功能对等；触发与定时因 API 调整。

### 3.2 暗影提灯

冷却 160t、粒子、SAN、脆弱效果与原版对齐；脆弱公式 amp0 由无效修正为 +20%（bugfix）。

### 3.3 融梦能量 / SAN

| 维度 | 原版 | 重写版 |
|------|------|--------|
| 存储 | Capability | Attachment（`MeltDreamEnergyData` / `SanData`） |
| 网络 | `*Message` | `*Payload` |
| 消耗策略 | 主模内大量直接消耗 | **有意**：主模保留 API + 生成 + HUD；消耗可外移附属 |

### 3.4 服务端延迟

| | 原版 queueServerWork | `api/util/ServerScheduler` |
|--|---------------------|-----------------|
| 语义 | delay tick 后执行 | 同 |
| 挂接 | MCreator 内置 | 主模 `ServerScheduler.register(NeoForge.EVENT_BUS)`（非 `@EventBusSubscriber(modid)`） |
| 轻载实际 | 常立即执行 | 严格 dueTick |
| 影响 | 法术多波同 tick 爆发 | 根因已解 |
| 位置 | 过程内联 | PasterDreamAPI 横切工具；`advanceForTest` 供 VERIFY |

### 3.5 BlockEntity 容器

原：`NonNullList` + `SidedInvWrapper`。  
新：`ItemStackHandler` + 直接 `IItemHandler`。代表：研究台、暗影高炉等。

### 3.6 网络

~18 Message → ~5 Payload；`PayloadRegistrar`；复杂度显著下降。

### 3.7 P1 API 上收（2026-07-30）

| 能力 | API | 主模 |
|------|-----|------|
| FluidType | `FluidTypeAPI` + `FluidBuilder.buildPair` | `PDFluidsType` 仅 Holder；具体 FluidType/Fluid 类仍主模 |
| 容器 Menu | `SimpleContainerMenu` | 简单箱/桌继承；机台可复用 helper |
| Block datagen | `ApiBlockModelProvider` / `ApiBlockTagProvider` | PD* 薄壳 + 手写 extra tags |
| BGM | `api/audio` 状态机与表/Lookup | `client.audio` 播放与交叉淡化、biome 表数据 |
| Item 注册 | `ItemAPI.REGISTRY` 与 `PDItems.ITEMS` 同 modid 双轨 | **约定**：新简单物品优先 ItemAPI；复杂/BlockItem 可留 PDItems |

## 6. 有意增强 / 设计变更（非缺失）
