## 7. 读报告与环境变量

```bash
python3 -c "import json;d=json.load(open('PasterDream/run/pd_verify_report.json'));print(d['pass'],d['fail'])"
```

| 环境变量 | 默认 | 含义 |
| :--- | :-: | :--- |
| `PASTERDREAM_VERIFY=1` | 关 | 移植终验时间线 |
| `PASTERDREAM_VERIFY_SUITES` | `all` | 逗号分隔套件名 |
| `PASTERDREAM_VERIFY_SHADOW_CHOICE` | `dark` | main-flow 专用；`dark`（默认）/ `light`（影之抉择路径分歧） |
| `PASTERDREAM_VERIFY_KEEP_OPEN` | **开** | `0`/`false` = 测完退出 |
| `PASTERDREAM_VERIFY_SHADOW_CHOICE` | `dark` | main-flow 影之抉择：`dark`/`shadow` 或 `light`；非法 fail fast |
| `PASTERDREAM_SMOKETEST=1` | 关 | 炼药锅等冒烟（可与 VERIFY 同开） |

| 路径 / 类 | 用途 |
| :--- | :--- |
| `pd_porting_manifest.json` | 注册期望名 |
| `smoketest/PDSmokeTest` | 冒烟；删档建世界 |
| `smoketest/PDPortingVerifyTest` | 注册 diff + 行为时间线调度 |
| `smoketest/PDGalleryVerifyHooks` | 方块总览 + 结构维度 |
| `smoketest/PDEntityGalleryVerifyHooks` | 实体展台 |
| `smoketest/PDWorkshopVerifyHooks` | 工坊 |
| `smoketest/PDStructureVerifyHooks` | 结构生成 |
| `smoketest/PDCurioVerifyHooks` | 饰品（CORE · curios） |
| `smoketest/PDStaleCommentVerifyHooks` | 注释相关行为抽测（stale-comments） |
| `smoketest/PDTwilightLanternVerifyHooks` | 暮影之笼链路 VERIFY（twilight-lantern；P0 正向） |
| `smoketest/PDWindJourneyVerifyHooks` | 第三梦境风旅核实（wind-journey） |
| `smoketest/PDSecondDreamVerifyHooks` | 第二梦境灯影 VERIFY（second-dream） |
| `smoketest/PDMainFlowVerifyHooks` | 主干全链路 VERIFY（main-flow；染梦→暮影→灯影抉择→竞技场→风旅；无名全对话 + SHADOW_CHOICE） |
| `PasterDream/run/saves/test-audit` | 测试世界（每次重建） |
| `PasterDream/run/pd_verify_report.json` | 机器可读报告 |
| `PasterDream/run/crash-reports/` · `logs/latest.log` | 崩溃 / 日志 |

展台说明：

- **方块总览**（出生点东/南）：主台静物全量；特展带用物品框展示结构触发块 / 唤星 / 流体。
- **实体展台**（西侧）：刷怪蛋木桶 · 无蛋名签桶 · 活体玻璃笼（NoAI+无敌）。

## 8. 打包可安装 jar（内嵌 API）

产物：`build/dist/pasterdream-<version>.jar`（`PasterDreamAPI` 已合并，无独立 mods.toml）。  
玩家/整合包另需 **GeckoLib + Curios**（required）；Player Animator / JEI 可选。

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk sh gradlew packageMod
```

`assemble` / `build` 依赖 `packageMod`。带 `api` classifier 的产物仅供开发，勿放 `mods/`。
