# 第二梦境 · 灯影之下（lamp_shadow_world）

> **类别**：参考 · 玩法 / 世界 / 地牢 / Boss  
> **日期**：2026-07-28  
> **功能总览** → [`功能状态.md`](功能状态.md)  
> **前置流程** → [`暮影之笼.md`](暮影之笼.md)（据点守卫 → 真影床首进）  
> **原版对照** → `LampShadowPr0/Pr1` · `ShadowDungeonPortalPr*` · `ShadowNpc0Pr0` · `ShadowSelectEndPr*` · `AaroncosArenaPortalsPr0` · `AaroncoshandspawnblockPr*`

维度：`pasterdream:lamp_shadow_world`（`PDDimensions.LAMP_SHADOW_WORLD_LEVEL_KEY`）。  
图鉴：第二层梦境；黑色主调、低能见度、大量敌对；精神值约 **-1.2/分钟**。  
本页从**进入灯影**写到**击败亚伦柯斯之触**，含暗影地牢、无名对话、影之抉择与竞技场。

---

## 0. 一句话

**首进**靠暮影之笼据点 + 真影床（`hide_9`）；**再进**可自制暮影长床（需 `shadow_start`）。  
灯影内：捡笔记残页 → 研究台 → 黑金属 → **暗影地牢**（多次，底有**无名**）→ 主世界暗影入侵解锁 `npc_3` → 再回地牢对话到 `npc_5` → **影之抉择**得 `d_0` → **阴影之地**找手形遗迹传送门 → **亚伦柯斯竞技场**打左右手 → `e_0` + 战利品。

## 1. 如何进入灯影

| 入口 | 条件 | 结果 |
| :--- | :--- | :--- |
| **真影床** `true_shadow_bed`（结构内） | 夜/雷暴；床上 2 格暮影之笼 `key=true`；`achievement_hide_9` | 理智 **-10** → 灯影 |
| **暮影长床** `shadow_bed`（可合成） | 夜/雷暴；**不在**灯影；`achievement_shadow_start` | 理智 **-10**；补授 `shadow_a_1` → 灯影 |

实现：`TrueShadowBedBlock` · `ShadowBedBlock` · `ShadowBedBlock.teleportToLampShadowWorld`（原 `WorldSpawnPr1`）。

### 1.1 落点

| 项 | 值 |
| :--- | :--- |
| 水平 | `(0.5, ·, 0.5)` |
| 高度 | 源世界 `(0,100,0)` 为空气 → **104**，否则 **154**（原版语义保留） |
| 包 | `WIN_GAME` · 能力/效果同步 · 维度事件 **1032** |

首进维度自动成就 **`achievement_shadow_start`**（`changed_dimension` → `lamp_shadow_world`，100 XP）。

### 1.2 进维瞬间（原版 / 配置）

原版 `LampShadowPr0`（进维 title「灯影之下」）：

- 配置 **`in lamp shadow give pale boneneedle`**（`PDCommonConfig.IN_LAMP_SHADOW_GIVE_PALE_BONENEEDLE`，**默认 false**）为 true 时给 **苍白骨针** 1 个。  
- Neo：`PlayerDataEvents` 目前只同步 San/融梦；title/赠针若未接线则以配置与原版为准（图鉴仍写「进入后给予骨针」——与默认 false 的差异见 §10）。

离开灯影后若已 `npc_2` 且未 `e_0`，原版 `LampShadowPr1` 会挂 **`shadow_spyon_buff`**（暗影窥视，主世界入侵相关）；Neo 在 `PDEffects` 入侵逻辑中使用同系效果。

## 5. 暗影地牢

实现：`ShadowDungeonPortalBlock`（完好）· `BrokenShadowDungeonProtalBlock`（破损，拼写 protal 同原版）· 结构 `structure_block_17` / jigsaw `shadow_dungeon`。

### 5.1 完好传送门 BE 键

| 键 | 含义 |
| :--- | :--- |
| `exit` | 出口门（tabitem_1 标记） |
| `cd` / `time` | 冷却中；`time` 每 20t +1，**≥1800**（约 30 分钟）解除 |
| `layer1..5` | 各层随机卷号 |

### 5.2 交互

1. **主手 `tabitem_1`**：`exit=true`，提示「已设置为出口！」  
2. **`exit==true`**：信标音 · animation · 8 格内玩家 3s 倒计时 → `(x+0.5, y+66, z+2.5)`（上浮出口）  
3. **遗迹完整**（`pos+(0,-2,0)` = `shadow_dungeon_block_0` 且 `+(1,-2,0)` = `block_1`）且 **无 cd**：  
   - `generateDungeon`：随机五层、清场、放门、分帧贴模板  
   - 冷却开启；3s 倒计时 → **(x-3.5, y-19, z+0.5)**  
   - 若 `b_0` 且未 `c_0` → 授 **`achievement_shadow_c_0`**  
4. 完整但 cd 中：actionbar「地牢刷新冷却中 剩余：N秒」  
5. 结构不完整：「遗迹结构不完整」

### 5.3 五层模板（相对传送门）

| 层 | Y 偏移 | 候选模板 |
| ---: | ---: | :--- |
| 1 | -28 | `shadow_dungeon_0..5`（6） |
| 2 | -37 | `shadow_dungeon_10..13`（4） |
| 3 | -46 | `shadow_dungeon_7..9`（3） |
| 4 | -55 | `shadow_dungeon_6`, `_14`（2） |
| 5 | -64 | **`shadow_dungeon_npc_0` / `_1`**（无名层） |

层间放置 `shadow_dungeon_door_0`（多处 y-29/-38/…）；底层另有 `SHADOWDUNGEONDOOR_2`。  
清场：以 `(x, y-42, z)` 为中心约 44 格实体丢弃。

### 5.4 破损门修复

| 条件 | 结果 |
| :--- | :--- |
| `y ≤ 20` | 「地牢的结构被破坏，传送门没有反应」 |

### 5.5 地牢门（原版 vs Neo）

## 6. 无名（shadow_npc_0）

类：`ShadowNpc0Entity`。玩家/火焰不伤；对话锁 `switch`；附近约 8 格玩家同步听台词。

### 6.1 分支总表

| 条件 | 阶段 | 授予 | 要点 |
| :--- | :--- | :--- | :--- |
| 无 `npc_0` | Stage0 初见 | **`npc_0`** + 金块 | 自称「无名」；地牢会变；「下去是出口」 |
| `npc_0` 无 `npc_1` | Stage1 | **`npc_1`** | 回忆/诅咒；劝离 |
| `(npc_1∧¬npc_2) ∨ (npc_2∧¬npc_3)` | Stage2 **第三段** | **`npc_2`** | 强劝离开；配置开则 **TP 主世界** |
| 有 `npc_3` 无 `npc_4` | Stage4 | **`npc_4`** | 主世界影子；「下次见面」 |
| 有 `npc_4` 无 `npc_5` | Stage5 | **`npc_5`** | 下层坟墓与暮影长床；「去轻抚暮影长床做第一选择」 |

**没有** Stage 直接授 `npc_3`：见 §6.2。

### 6.2 `npc_3`：主世界暗影入侵

`PDEffects` · `shadowIntrudeCalm`：入侵结束且附近无虚弱尖喙等 → 平息时若无 `npc_3`：

- 授 **`achievement_shadow_npc_3`**  
- 「你对这些暗影生物会来到这里感到疑惑」「或许我们应该再去找一次无名…」  
- 移除窥视类效果  

流程含义：第三段对话被送回主世界 → 经历影子入侵 → 再带 `npc_3` 回地牢推进 Stage4/5。

### 6.3 第三段回传配置

`PDCommonConfig.SHADOW_NPC_THIRD_DIALOGUE_AFTER_TP_PLAYER_BACK_TO_OVERWORLD`（默认 true）→ `teleportPlayerToOverworldSpawn`。

## 8. 亚伦柯斯竞技场与 Boss

### 8.1 入口

| 项 | 说明 |
| :--- | :--- |
| 位置 | 灯影 **`biome_shadow_0`** 自然结构 `aaroncos_arena_portals`（Ruin/Jigsaw，`PDRuinsRegistration.registerAaroncosArenaPortal`） |
| 方块 | `AaroncosArenaPortalsBlock`（半砖、光 15、无碰撞、不可破坏） |
| 感染 | 每 tick 约 2%：半径 3 草/土/石等 → 影块/厚影/影石砖等 |
| 踩上 | → `aaroncos_arena_world` **(0.5, 70, 0.5)** + 缓降 |

**资格（原版）**：`AaroncosArenaPortalsPr0` 要求 **`d_0` 或创造**，否则「尚未完成前置进度」。  
**Neo 现状**：`entityInside` **未检 d_0**（与 lang `message.pasterdream.aaroncos_arena_portals.locked` / 原版不一致 → §10）。

### 8.2 进入竞技场维度 `PDArenaEvents`

目标维 = 竞技场时：

1. 场内玩家 **&lt; 2**：放置 `aaroncos_arena.nbt`（锚约 -35,0,-35）、清非玩家实体（约 99 格）、`initializeBossFight` → `NOT_SUMMONED`  
2. 玩家对齐 **(0, 70, 0)**  
3. 缓降 600t（另有入口 120t）  

图鉴：禁止改造 + 缓降；精神约 **-4.8/min**。  
原版进场 **冒险模式**；Neo 入口侧未见 `guard_block_buff` / 强制冒险（§10）。

### 8.3 开战

结构内 **亚伦柯斯之眼** `AaroncosHandSpawnBlock`：

| 阶段 | 右键 |
| :--- | :--- |
| `NOT_SUMMONED` / 可重开 | `triggerBossSummon` → `SUMMONING` → 刷左右手 |
| `VICTORY` | 单人回主世界出生点（生存） |

生成（`spawnAaroncosBosses`）：

- 左：中心 +12 X，面朝 180° · `AaroncosLefthand0Entity`  
- 右：中心 -12 X，面朝 0° · `AaroncosRighthand0Entity`  
- 召唤中：无敌、AI 关、spawn 动画（左约 80t / 右约 40t）→ `FIGHTING`  

### 8.4 Boss 摘要

| | 左触 | 右触 |
| :--- | :--- | :--- |
| 属性量级 | 500 HP · 高甲高攻 | 500 HP · 较低甲 |
| 技能向 | 冲锋 / 三段砸地 / 受击剑技 | 魔球 / 漩涡方块 / 受击音叉图腾 |
| 共通 | 飞行；低血鲜血锁链（影手+致盲减速等） | 同左基类 |

双手均 `on*HandDeath` 且双灭 → **`triggerVictorySequence`**。

### 8.5 胜利

1. 阶段 `VICTORY`  
2. `(0, 69, 0)` 放 **`aaroncos_hand_chest`** + 粒子/音效  
3. +40t 掉落（地面实体，非箱内）：  
   - 必掉 **`pure_horror`**  
   - 场内有人 `talent_light` → `white_flower_body` + `white_crystal`  
   - 场内有人 `talent_shadow` → `degenerate_bodys` + `shadow_hilt`  
4. 实体 loot 另含唱片 `aaroncos_disc`、影息、黑金属等  
5. 再右键之眼 → 回主世界  

**成就 `e_0`（吹影镂尘）**：原版双手死亡过程授予；Neo `PDArenaBossManager` **注释有、代码未 grant**（§10）。父节点 `d_0`，challenge，1000 XP。
