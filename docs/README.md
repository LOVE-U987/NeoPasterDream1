## 分类原则

| 类别 | 放什么 | 不放什么 |
| :--- | :--- | :--- |
| 功能状态 | 「玩家能不能玩到」+ **唯一开放项表** | 命令长表、API 对比、历史 bug 明细 |
| 验证复现 | 可复制命令与工具入口 | 模块还原表 |
| 架构差异 | 「怎么实现的 / 为何不同」 | 是否缺功能 |
| 上收边界 | 何物进 API vs 留主模 | 功能缺口正文、具体搬迁 PR 日志 |
| 注释审计 | 注释 vs 代码 | 功能缺口正文（只链到功能状态） |
| 玩法逻辑 | 单系统生成/事件/进维时序 | 全模组进度表、命令大全 |
| 审查（归档） | 结案快照、当时 Critical/High | 新开放项（仍只写功能状态 §3） |
| 归档 | 已结案、不再回退 | 新开放项 |
