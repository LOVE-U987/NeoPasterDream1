## 分类原则

| 类别 | 放什么 | 不放什么 |
| :--- | :--- | :--- |
| 功能状态 | 「玩家能不能玩到」 | 命令长表、API 对比、历史 bug 明细 |
| 验证复现 | 可复制命令与工具入口 | 模块还原表 |
| 架构差异 | 「怎么实现的 / 为何不同」 | 是否缺功能 |
| API 关系 / 上收边界 | 管线接线、何物进 API vs 留主模 | 功能缺口正文、具体搬迁 PR 日志 |
| 注释审计 | 注释 vs 代码 | 功能缺口正文（只链到功能状态） |
| 玩法逻辑 | 单系统生成/事件/进维时序 | 全模组进度表、命令大全 |
| 待办 | 已核实缺口、验收标准、动手顺序 | 已修复结论（修完并入功能状态/玩法文档） |
| 审查 | 对「已收口」声明的交叉核实结论 | 新功能实现本身、日常待办勾选 |
| 归档 | 已结案、不再回退 | 新开放项 |
