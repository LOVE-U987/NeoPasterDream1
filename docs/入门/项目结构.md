# 项目结构

> 本文档介绍 PasterDream 项目的多模块架构和关键目录。

---

## 模块总览

PasterDream 采用 **5 模块架构**,各模块职责清晰:

```
NeoPasterDream1/
├── PasterDreamAPI/           # API 模块 — 可复用框架
├── PasterDream/              # 主模块 — 游戏内容
├── PasterDreamSpells/        # 附属模块 — 法术系统
├── PasterDreamSanity/        # 附属模块 — 理智系统
├── PasterDreamMeltDream/     # 附属模块 — 融梦能量系统
├── docs/                     # 开发文档
├── tools/                    # 工具脚本
└── libs/FixPasterDream-main/ # 原模组 (只读参考)
```

---

## 模块依赖关系

```
PasterDreamAPI       ← 独立 (无项目依赖)
    ↑
PasterDream          ← 依赖 API + [可选] Spells/Sanity/MeltDream
    ↑
PasterDreamSpells    ← 依赖 API
PasterDreamSanity    ← 依赖 API
PasterDreamMeltDream ← 依赖 API
```

**关键规则**:
- 附属模块只依赖 API,不依赖主模块
- 主模块通过 jarJar 内嵌 API
- 附属模块为 thin 发行,运行时需主模组提供 API

---

## 模块归属决策

新代码按以下条件判断归属:

| 条件 (满足任一) | 目标模块 |
|----------------|---------|
| API 接口 / Builder / Facade / Result / Config 类 | → `PasterDreamAPI` |
| 会被多个业务模块引用的类 | → `PasterDreamAPI` |
| 属于注册体系 (DeferredRegister/DataGen) | → `PasterDreamAPI` |
| 需要被其他模组作为库依赖 | → `PasterDreamAPI` |
| 法术系统 (卷轴/投射物/立场/法术效果) | → `PasterDreamSpells` |
| 理智系统 (San值/环境修饰/低San惩罚) | → `PasterDreamSanity` |
| 融梦能量系统 (能量池/恢复/消耗) | → `PasterDreamMeltDream` |
| 以上均不满足 (方块/物品/实体/渲染/客户端代码) | → `PasterDream` |

> API/Builder/注册门面 → API 模块;法术 → Spells;理智 → Sanity;融梦 → MeltDream;其余 → 主模块。

## API 模块结构

**路径**: `PasterDreamAPI/src/main/java/com/pasterdream/pasterdreammod/api/`

```
api/
├── PasterDreamAPI.java          # 统一注册入口
├── block/                       # 方块 API (SimpleBlockBuilder, VariantSetBuilder, BatchBlockBuilder)
├── entity/                      # 实体 API (EntityBuilder, EntitySkill, EntityTag)
├── item/                        # 物品 API (SimpleItemBuilder, FoodItemBuilder, ToolItemBuilder, CurioItemBuilder)
├── dimension/                   # 维度 API (DimensionBuilder, DimensionResult)
├── ruin/                        # 遗迹 API (RuinBuilder, StructureSetBuilder)
├── particle/                    # 粒子 API (ParticleBuilder)
├── effect/                      # 效果 API (MobEffectAPI, ImpactFrameAPI, ScreenEffectAPI, ...)
├── worldgen/decor/              # 装饰物 API (DecorationBuilder, TreePlacerAPI)
├── fluid/                       # 流体 API (FluidAPI, FluidTypeAPI)
├── curio/                       # 饰品 API (CurioBuilder)
├── menu/                        # 菜单 API (SimpleContainerMenu)
├── audio/                       # 音乐 API (BgmAPI, BiomeMusicTable)
├── san/                         # 理智 API (SanAPI, SanData)
├── meltdream/                   # 融梦 API (MeltDreamEnergyAPI, MeltDreamEnergyData)
├── spell/                       # 法术 API (ISpell)
├── blockentity/                 # 方块实体 API (FreeDataBlockEntity)
├── attachment/                  # 数据附件 (PDPlayerAttachments)
├── attribute/                   # 自定义属性 (APIAttributes)
├── config/                      # 配置注册 (PDAddonConfigRegistry)
├── network/                     # 网络包定义 (10 个 Payload 类)
├── data/                        # 数据生成辅助
├── util/                        # 工具类
└── client/                      # 客户端 API
    ├── effect/                  # 客户端效果处理器
    ├── sky/                     # 天空盒 API
    ├── particle/                # 粒子渲染
    └── renderer/                # 渲染器工具
```

## 主模块结构

**路径**: `PasterDream/src/main/java/com/pasterdream/pasterdreammod/`

```
pasterdreammod/
├── PasterDreamMod.java          # 模组入口 (@Mod)
├── registry/                    # 注册系统 (48 个注册文件)
│   ├── blocks/                  # 方块注册 (17 个文件)
│   ├── items/                   # 物品注册 (14 个文件)
│   ├── creativetabs/            # 创造标签 (12 个文件)
│   └── *.java                   # 实体/效果/粒子/维度等注册
├── block/                       # 方块实现 (112+ 个类)
├── entity/                      # 实体实现
│   ├── mob/                     # 生物实体 (33 个)
│   ├── projectile/              # 投射物 (13 个)
│   └── damage/                  # 伤害免疫
├── item/                        # 物品实现
├── client/                      # 客户端代码
│   ├── renderer/                # 渲染器
│   │   ├── entity/              # 实体渲染器 (34 个)
│   │   ├── block/               # 方块实体渲染器
│   │   └── item/                # 物品渲染器
│   ├── gui/                     # GUI/Screen
│   ├── particle/                # 粒子
│   ├── sky/                     # 天空盒渲染
│   └── effect/                  # 客户端效果
├── world/                       # 世界事件
├── worldgen/                    # 世界生成
├── config/                      # 配置文件
├── network/                     # 网络包
├── data/                        # 数据生成
├── integration/                 # 第三方集成 (JEI, KubeJS)
└── command/                     # 命令
```

## 关键目录说明

### tools/

64 个 Python 脚本（截至 2026-09-15）,用于:

- **验证**: `verify_resource_closure.py`, `verify_config_port.py`
- **扫描**: `scan_pinyin_resources.py`, `scan_stack_buff_parity.py`
- **资源处理**: `grayify_texture.py`, `gen_sky_textures.py`
- **代码迁移**: `migrate_decor_api.py`, `rename_pinyin_resources.py`
- **语言**: `fix_missing_lang.py`, `check_lang.py`

### libs/

原模组代码 (**只读参考**,不可修改):

- `libs/FixPasterDream-main/` — Forge 1.20.1 MCreator 生成的原版代码
