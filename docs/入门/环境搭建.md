# 环境搭建

> 本文档指导你配置 PasterDream 项目的开发环境。

---

## 环境要求

| 工具 | 版本 | 说明 |
|------|------|------|
| Java | 21 | 必须,JDK 21 LTS |
| Gradle | Wrapper 9.2.1 | 以仓库 `gradle/wrapper/gradle-wrapper.properties` 为准,无需单独安装 |
| Git | 2.x | 版本控制 |
| IDE | IntelliJ IDEA (推荐) | Eclipse 也可,但 IDEA 对 NeoForge 支持更好 |

### IntelliJ IDEA 插件推荐

- **Minecraft Development** — Minecraft 模组开发辅助
- **Gradle** — Gradle 支持 (IDEA 自带)
- **Lombok** — 如果使用 Lombok (本项目未使用)

---

## 克隆项目

```bash
git clone https://github.com/LOVE-U987/NeoPasterDream1.git
cd NeoPasterDream1
```

---

## 首次构建

### 1. 确认 Gradle Wrapper

仓库已包含 `gradlew`、`gradlew.bat` 和 Wrapper 配置。直接使用仓库自带的 Wrapper；如果文件缺失,先重新获取完整仓库,不要自行生成不同版本的 Wrapper。

### 2. 编译项目

```bash
# Windows
.\gradlew compileJava

# macOS/Linux
./gradlew compileJava
```

首次编译会下载 NeoForge、GeckoLib 等依赖,可能需要几分钟。

### 3. 运行数据生成器

```bash
.\gradlew runData
```

这会生成方块标签、模型等数据文件。

### 4. 启动客户端

```bash
.\gradlew runClient
```

首次启动会下载 Minecraft 资源,请耐心等待。

## 常用命令

| 命令 | 说明 |
|------|------|
| `.\gradlew compileJava` | 编译所有模块 |
| `.\gradlew :PasterDream:compileJava` | 仅编译主模块 |
| `.\gradlew :PasterDreamSpells:compileJava` | 仅编译法术模块 |
| `.\gradlew :PasterDreamSanity:compileJava` | 仅编译理智模块 |
| `.\gradlew :PasterDreamMeltDream:compileJava` | 仅编译融梦模块 |
| `.\gradlew runData` | 运行数据生成器 |
| `.\gradlew runClient` | 启动客户端 |
| `.\gradlew runServer` | 启动服务器 |
| `.\gradlew packageMod` | 打包所有模组 |

## IDE 配置

### IntelliJ IDEA

1. 打开项目: `File → Open` → 选择项目根目录
2. 等待 Gradle 同步完成 (右下角进度条)
3. 配置 JDK: `File → Project Structure → SDKs` → 添加 JDK 21
4. 设置编码: `File → Settings → Editor → File Encodings` → 全部设为 UTF-8

### 运行配置

项目已包含预定义运行配置 (`.run/` 目录):

- `PasterDream` — 启动客户端
- `PasterDream Server` — 启动服务器
- `PasterDream Data` — 运行数据生成
- `PD SMOKETEST+VERIFY` — 运行预设基础验证（专项套件需显式选择,见[测试指南](../开发指南/测试指南.md)）

## 故障排除

### 编译失败: Java 版本不匹配

确保使用 JDK 21:

```bash
java -version
# 应显示 openjdk version "21.x.x"
```

### Gradle 同步失败

1. 删除 `.gradle/` 目录
2. 运行 `.\gradlew clean`
3. 重新打开 IDE

### 客户端启动失败

1. 检查 `run/` 目录下的日志文件
2. 确保已运行 `.\gradlew runData` 生成数据文件
3. 检查 Minecraft 版本是否为 1.21.1
