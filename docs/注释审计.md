## 0. 分类

| 类别 | 含义 | 处理 |
|------|------|------|
| **Stale - complete** | 注释称尚未/待/省略，实现已完整 | 改注释为「防御性」或删误导句；逻辑可留 |
| **Partial** | 系统在，未接线或与原版不完全一致 | 标注「已定义未读」；可选接线 |
| **Accurate (defensive)** | 守卫仍有价值 | 保留；注释写「防御性」 |
| **Accurate (intentional)** | 有意不移植 | 写明「有意省略」 |

## 6. 维护

1. **优先改注释**：新代码勿再写「尚未移植 / 待移植 / 暂缓」除非真未实现。  
2. **逻辑守卫**（null / AIR）保留，统一写「防御性检查」。  
3. **配置**：抖动 / 时之沙 BAN / 赠针默认 已于 2026-07-30 收口。  
4. 扫描：
   ```bash
   rg -n '尚未|暂不|暂且|待移植|未还原|未实现|TODO.*移植|not yet|for now|省略|占位' \
      PasterDream/src/main/java --glob '*.java'
   ```
   （过滤玩家可见文案、工坊占位模型、VERIFY 自述后再判。）  
5. 验证：`PASTERDREAM_VERIFY=1 PASTERDREAM_VERIFY_SUITES=core …` → 关注 `stale-comments` 与 `curios`。
