# 客户端/服务端分离

> 本文档介绍 PasterDream 的客户端/服务端分离架构,包括事件总线、Dist 注解和网络包设计。

---

## 事件总线架构

PasterDream 使用 NeoForge 的双事件总线系统:

| 总线 | 用途 | 注解 |
|------|------|------|
| `modEventBus` | 模组生命周期事件 | `@EventBusSubscriber` |
| `NeoForge.EVENT_BUS` | 游戏运行时事件 | `@EventBusSubscriber` 或手动注册 |

---

## Dist 注解

### 服务端事件处理器

```java
@EventBusSubscriber(modid = MOD_ID)
public class ServerEvents {
    @SubscribeEvent
    public static void onPlayerTick(TickEvent.PlayerTickEvent event) {
        // 服务端逻辑
    }
}
```

### 客户端事件处理器

```java
@EventBusSubscriber(modid = MOD_ID, value = Dist.CLIENT)
public class ClientEvents {
    @SubscribeEvent
    public static void onClientSetup(FMLClientSetupEvent event) {
        // 客户端初始化
    }
}
```

### 关键规则

1. **客户端代码必须标记 `Dist.CLIENT`**
2. **客户端类不能在服务端加载** (会导致 `ClassNotFoundException`)
3. **使用反射调用客户端代码** (服务端安全)

### 两种注册模式

#### 模式一: @EventBusSubscriber (自动注册)

```java
@EventBusSubscriber(modid = MOD_ID)
public class PDEntityEvents {
    @SubscribeEvent
    public static void onEntityJoinLevel(EntityJoinLevelEvent event) {
        // 自动注册,无需手动添加监听器
    }
}
```

#### 模式二: 手动 addListener

```java
// 在 PasterDreamMod 构造函数中
modEventBus.addListener(this::onCommonSetup);
NeoForge.EVENT_BUS.addListener(this::onPlayerTick);

private void onCommonSetup(FMLCommonSetupEvent event) {
    // 手动注册
}
```

## 网络包设计

### Payload 定义

```java
// S2C (服务端 → 客户端)
public record AtmosphereEffectPayload(float fogStart, float fogEnd, int color) implements CustomPacketPayload {
    public static final CustomPacketPayload.Type<AtmosphereEffectPayload> TYPE = 
        new CustomPacketPayload.Type<>(ResourceLocation.fromNamespaceAndPath(MOD_ID, "atmosphere_effect"));
    
    @Override
    public Type<? extends CustomPacketPayload> type() {
        return TYPE;
    }
}

// C2S (客户端 → 服务端)
public record StartCutscenePayload(CameraPos target, CurveType curve, EasingType easing) implements CustomPacketPayload {
    // ...
}
```

### 网络注册

```java
public class PDNetwork {
    public static void register() {
        PayloadRegistrar registrar = INSTANCE.registrar("1");
        
        // S2C Payloads
        registrar.playToClient(AtmosphereEffectPayload.TYPE, AtmosphereEffectPayload.STREAM_CODEC, AtmosphereEffectPayload::handle);
        registrar.playToClient(GhostEffectPayload.TYPE, GhostEffectPayload.STREAM_CODEC, GhostEffectPayload::handle);
        // ... 更多 S2C
        
        // C2S Payloads
        registrar.playToServer(StartCutscenePayload.TYPE, StartCutscenePayload.STREAM_CODEC, StartCutscenePayload::handle);
        registrar.playToServer(StopCutscenePayload.TYPE, StopCutscenePayload.STREAM_CODEC, StopCutscenePayload::handle);
    }
}
```

### 服务端安全模式

```java
// 客户端 VFX 处理器
public class PDClientVfx {
    public static void handleAtmosphereEffect(AtmosphereEffectPayload payload, IPayloadContext context) {
        // 使用反射避免服务端加载客户端类
        try {
            Class<?> handlerClass = Class.forName("com.pasterdream.pasterdreammod.client.effect.AtmosphereHandler");
            handlerClass.getMethod("handle", AtmosphereEffectPayload.class).invoke(null, payload);
        } catch (Exception e) {
            // 安全处理
        }
    }
}
```

## 数据附件

### 定义

```java
public class PDPlayerAttachments {
    public static final DeferredAttachmentType<SanData> SAN_DATA = 
        ATTACHMENT_TYPES.register("san_data", () -> AttachmentType.<SanData>builder()
            .serialize(SanData.CODEC)
            .build());
    
    public static final DeferredAttachmentType<MeltDreamEnergyData> MELTDREAM_ENERGY = 
        ATTACHMENT_TYPES.register("meltdream_energy", () -> AttachmentType.<MeltDreamEnergyData>builder()
            .serialize(MeltDreamEnergyData.CODEC)
            .build());
}
```

### 使用

```java
// 服务端
SanData sanData = player.getData(PDPlayerAttachments.SAN_DATA);
sanData.setSan(100);

// 客户端 (需要同步)
PDNetwork.sendToPlayer(new SanDataPayload(sanData.getSan()), player);
```

## 常见问题

### Q: 客户端代码在服务端加载了怎么办?

使用反射调用:

```java
// 错误 ❌
import com.pasterdream.pasterdreammod.client.ClientHandler;
ClientHandler.doSomething();

// 正确 ✅
try {
    Class<?> clazz = Class.forName("com.pasterdream.pasterdreammod.client.ClientHandler");
    clazz.getMethod("doSomething").invoke(null);
} catch (Exception e) {
    // 安全处理
}
```

### Q: 如何同步数据到客户端?

1. 定义 Payload
2. 在服务端发送
3. 客户端接收处理

```java
// 服务端发送
PDNetwork.sendToPlayer(new MyDataPayload(data), player);

// 客户端处理
public static void handle(MyDataPayload payload, IPayloadContext context) {
    context.enqueueWork(() -> {
        // 更新客户端数据
    });
}
```

### Q: 如何注册客户端事件?

使用 `@EventBusSubscriber(value = Dist.CLIENT)`:

```java
@EventBusSubscriber(modid = MOD_ID, value = Dist.CLIENT)
public class ClientEvents {
    @SubscribeEvent
    public static void onClientSetup(FMLClientSetupEvent event) {
        // 客户端初始化
    }
}
```
