# 架构总览

> 本文档介绍 PasterDream 的整体架构设计和核心理念。

---

## 设计理念

PasterDream 是原 PasterDream 模组面向 NeoForge 1.21.1 的**非官方移植项目**。项目以还原原模组的核心内容与玩法体验为目标，并结合新版本的平台能力进行适配、修复和改进。

### 项目性质与原作者态度

本项目由移植项目维护者独立开发和维护，未获得原作者的正式授权。原作者已知悉公开的移植计划，并回复“wow 加油！”。项目方将这一鼓励理解为对移植计划的默许；这不代表正式授权。

### 移植原则

| 项 | 说明 |
|---|---|
| 原模组 | `libs/FixPasterDream-main/` — Forge 1.20.1, MCreator 生成 |
| 移植实现 | 主模块、API 与附属模块 — NeoForge 1.21.1，手写重实现 |
| 内容目标 | 以原模组为参考，还原核心内容、流程和玩法体验 |
| 技术原则 | **不直接复制或修改原代码**，基于 NeoForge 1.21.1 API 重新实现，`libs/` 保持只读 |
| 差异管理 | 对原版的修复、改进和有意差异在设计文档中说明，并通过对应测试验收 |

### 为什么采用手写重实现?

1. **适配实现结构**：原模组由 MCreator 生成，移植采用手写代码组织原有内容与行为
2. **适配新版本 API**：根据 Minecraft 1.21.1 与 NeoForge 的机制重新实现注册、数据和运行逻辑
3. **提高可维护性**：通过模块化、统一 API 和测试驱动流程支持持续维护
4. **管理玩法差异**：在内容还原的基础上修复问题、改进体验；新增内容和有意差异按设计文档与测试要求验收

## 核心架构模式

### 1. Builder 模式 (Facade + Builder + Result)

所有主要注册系统都遵循相同的模式:

```java
// 实体注册示例
EntityResult<ShadowGolemEntity> result = EntityAPI.createEntity("shadow_golem")
    .category(MobCategory.MONSTER)
    .size(2.2f, 3.5f)
    .entityClass(ShadowGolemEntity.class)
    .attributes(ShadowGolemEntity::createAttributes)
    .skill(EntitySkill.builder("roar").build())
    .spawnEgg(0x2C2C2C, 0x6B3FAF)
    .build();
```

**优势**:
- 类型安全
- 链式调用,代码清晰
- 编译时检查
- 易于扩展

### 2. DeferredRegister 注册

所有注册都使用 NeoForge 的 `DeferredRegister`:

```java
public static final DeferredRegister<Block> REGISTRY = 
    DeferredRegister.create(Registries.BLOCK, MOD_ID);
```

**优势**:
- 延迟注册,性能优化
- 与 NeoForge 生命周期集成
- 支持数据生成

### 3. 事件驱动架构

客户端/服务端分离通过事件总线实现:

```java
@EventBusSubscriber(modid = MOD_ID, value = Dist.CLIENT)
public class ClientEvents {
    @SubscribeEvent
    public static void onClientSetup(FMLClientSetupEvent event) {
        // 客户端初始化
    }
}
```

## 注册流程

### 1. API 模块注册

```java
// PasterDreamAPI.java
public static void registerAll(IEventBus modEventBus) {
    BlockAPI.REGISTRY.register(modEventBus);
    EntityAPI.REGISTRY.register(modEventBus);
    ItemAPI.REGISTRY.register(modEventBus);
    ParticleAPI.REGISTRY.register(modEventBus);
    // ... 13 个 DeferredRegister
}
```

### 2. 主模块注册

```java
// PasterDreamMod.java
public PasterDreamMod(IEventBus modEventBus) {
    // 1. API 模块注册
    PasterDreamAPI.registerAll(modEventBus);
    
    // 2. 触发类加载 (填充 DeferredRegister)
    Object unusedBlocks = PDBlocks.BLOCKS;
    Object unusedEntityTypes = PDEntities.ENTITY_TYPES;
    // ... 10+ 个触发
    
    // 3. 显式注册
    PDItems.ITEMS.register(modEventBus);
    PDCreativeTabs.TABS.register(modEventBus);
    // ... 更多注册
}
```

## 设计优势

1. **模块化**: 5 个模块职责清晰,易于维护
2. **可扩展**: Builder 模式支持灵活扩展
3. **类型安全**: 编译时检查,减少运行时错误
4. **数据驱动**: 大量使用 JSON,便于修改
5. **性能优化**: 延迟注册、事件驱动
