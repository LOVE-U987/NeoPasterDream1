# 附属模块架构详解

> 本文档描述 PasterDreamSpells / PasterDreamSanity / PasterDreamMeltDream 三个附属模块的包结构现状。
> 与主模组的关系及 API 模块内部见 [API 架构详解](API架构详解.md)。

> **本文档是现状速览，不是规范源头。** 验收标准以测试为准（主模组 smoketest/VERIFY 覆盖
> 跨模块链路，见 [主模组架构详解](主模组架构详解.md) 第 8 节）。文档与代码不一致时，以代码为准。
> 统计数字截至 2026-09-15。

---

## 1. 附属共同模式

三个附属模块共享同一套发行与组织方式：

| 项 | 约定 |
|----|------|
| 发行模式 | thin 发行：不内嵌 PasterDreamAPI，由主模组打包提供 |
| 构建依赖 | `implementation project(':PasterDreamAPI')`（编译期依赖 API） |
| 运行时前置 | PasterDream 主模组 |
| 主类 | `PasterDream<X>Mod`，构造器只做自身注册（API 层由前置自注册） |
| 包根 | `com.pasterdream.pasterdreammod.pasterdream<域>` |
| 典型结构 | `config/`（自身配置）+ `registry/`（自身 DeferredRegister）+ 业务包 + `client/`（客户端） |

附属模块通过 API 的**配置接口**接入玩法系统：Sanity 实现 `ISanSystemConfig`，MeltDream 实现 `IMeltDreamEnergySystemConfig`（接口定义见 [API 架构详解](API架构详解.md) 4.4）。实现注册到 API 侧的 `SanConfigRegistry` / `MeltDreamEnergyConfigRegistry`，主模组消费时只依赖 API 接口，不反向依赖附属。

## 2. PasterDreamSpells（24 类）

法术系统附属。包根：`...pasterdreamspells`。

| 包 | 类数 | 内容 |
|----|-----|------|
| 根级 | 1 | `PasterDreamSpellsMod`（主类） |
| `config/` | 1 | `PDSpellsConfig` |
| `registry/` | 5 | `PDSpellsItems` / `PDSpellsEntities` / `PDSpellsEffects` / `PDSpellsParticles` / `PDSpellsSounds` |
| `item/` | 1 | `SpellItem`（法术卷轴物品） |
| `effect/` | 1 | `SpellEffects`（法术效果表） |
| `entity/mob/` | 2 | `FurySpellFieldEntity` / `HealingSpellFieldEntity`（法术立场） |
| `entity/projectile/` | 1 | `SpellProjectileEntity`（法术投射物） |
| `event/` | 1 | `PDSpellsEntityEvents` |
| `client/` | 1 | `PDSpellsClientSetup` |
| `client/model/entity/` | 2 | 法术立场模型 |
| `client/renderer/entity/` | 2 | 法术立场渲染器 |
| `client/particle/` | 6 | 法术粒子行为类（怒灵/治疗/毒气/雪晶/黄烟等） |

与 API 的引用关系（取证）：主要消费 `util`、`config`、`attribute`、`particle` 包；法术实体基类（`AbstractWandProjectileEntity` 等）与特效系统均来自 API/主模。

---

## 3. PasterDreamSanity（5 类）

理智系统附属。包根：`...pasterdreamsanity`。

| 包 | 类数 | 内容 |
|----|-----|------|
| 根级 | 2 | `PasterDreamSanityMod`（主类）、`PDSanityHelper` |
| `config/` | 1 | `PDSanityConfig`（实现 API `ISanSystemConfig`，注册到 `SanConfigRegistry`） |
| `registry/` | 2 | `PDSanityItems`、`PDSanityEffects` |

分工边界：San 值的 Attachment 定义、Payload、数据载体在 API（`san` 包）与主模（`attachment`），**环境修饰 tick 与低 San 惩罚逻辑在本附属**。主模 `PDSanityTickVerifyHooks` 验证其链路。

---

## 4. PasterDreamMeltDream（6 类）

融梦能量系统附属。包根：`...pasterdreammeltdream`。

| 包 | 类数 | 内容 |
|----|-----|------|
| 根级 | 2 | `PasterDreamMeltDreamMod`（主类）、`PDMeltDreamEvents`（能量 tick/事件） |
| `config/` | 1 | `PDMeltDreamConfig`（实现 API `IMeltDreamEnergySystemConfig`） |
| `registry/` | 2 | `PDMeltDreamItems`、`PDMeltDreamEffects` |
| `item/` | 1 | `MeltdreamEnergy0RingItem`（能量指环） |

分工边界：能量 Attachment/Payload/数据载体在 API（`meltdream` 包）与主模，**能量池恢复/消耗规则在本附属**。炼药锅注入融梦液体等交互链路由主模内容触发。
