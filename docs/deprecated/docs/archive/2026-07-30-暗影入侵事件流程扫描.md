## 1. 玩家路径（正常游玩）

```
主世界暮影之笼 → hide_9 → 真影床进灯影（shadow_start）
        ▼
灯影地牢 jigsaw（shadow_dungeon_npc_*）遇见无名
无名 Stage0 → Stage1 → Stage2（授 npc_2）
        │  配置 SHADOW_NPC_THIRD… 默认 true → TP 主世界出生点
        │  若配置关 TP：玩家自行离开灯影亦可
        ▼
LampShadowEvents.onLeaveLampShadow
  if npc_2 && !e_0 → addEffect(SHADOW_SPYON_BUFF, 32000, 0, false, false)
  PDEffectEvents：cures.clear()（牛奶不可清）
        ▼
主世界 · 夜晚 · 脚下亮度 ≤7 · 每 tick 0.05%
  → Phase1：shadow_intrude=true，文案+DARKNESS+shadow_door
        ▼
Phase2：~2%/tick 尝试刷 WEAKENESS_TERRORBEAK + SHADOW_HAND
  number>4 且 50% → shadow_intrude_end=true
        ▼
平息其一：
  A) end && 32 格 AABB 内无 WeakenessTerrorbeak
  B) level.isDay() && intrude
        ▼
shadowIntrudeCalm
  清 flag → 「影子归于平息...」
  若 !npc_3：award achievement_shadow_npc_3 + 两条 §7 提示 + removeEffect(spyon)
        ▼
回灯影对话 → Stage4（npc_4）→ Stage5（npc_5）→ 影之抉择 …
  （e_0：竞技场胜利再 remove spyon + 授 e_0）
```

## 2. 分路扫描结论

### 2.1 Buff 挂载与进入管道

| 项 | 状态 | 证据 |
| :--- | :---: | :--- |
| 上游进灯影 | **PASS** | 暮影笼 `TwilightLanternBlock` → `hide_9`；真影床 `TrueShadowBedBlock` → 灯影；`achievement_shadow_start` 靠 `changed_dimension` |
| 地牢无名实体 | **PASS**（结构依赖） | jigsaw `shadow_dungeon_npc_0/1.nbt`（`ShadowDungeonPortalBlock` 层）；结构失败则找不到无名（VERIFY `findOrSpawnNpc` 兜底） |
| Stage0–2 对话 | **PASS** | `ShadowNpc0Entity.mobInteract`：`(done1&&!done2)\|\|(!done3&&done2)` → Stage2 授 `npc_2` |
| 离灯影授 buff | **PASS** | `LampShadowEvents.java:60-68`：`from == LAMP_SHADOW` 且 `npc_2 && !e_0`；原版 `LampShadowPr1` 同条件 |
| 时长 / 可见性 | **PASS** / **PARITY** | 32000t；`false,false`（非 ambient、隐藏粒子）与原版一致 |
| 牛奶不可清 | **PASS** / **PARITY** | `PDEffectEvents.java:71-80` `getCures().clear()`；原版 `getCurativeItems()` 空列表 |
| Stage2 → 主世界 | **PASS** | `startStage2` + 配置默认 **true**（`PDCommonConfig.SHADOW_NPC_THIRD…`）；TP 带 WIN_GAME / 效果包重发 |
| 配置关 TP | **PASS**（旁路） | 不自动 TP，玩家离开灯影仍挂 buff；VERIFY 有「再进再出」兜底 |
| onTick 每 tick | **PASS** | `PasterDreamEffect.shouldApplyEffectTickThisTick` 默认 true；builder `.onTick(shadowIntrudeTick)` |
| 生产授 buff 唯一源 | **PASS** | 生产 `addEffect(SHADOW_SPYON_BUFF)` 仅 `LampShadowEvents`（+ 测试夹具）；`e_0` 时 `PDArenaBossManager` **移除** |
| 事件注册 | **PASS** | `PasterDreamMod` 注册 `LampShadowEvents.onPlayerChangedDimension` |

**阻断点**：无。未完成 `npc_2` 或已 `e_0` 则不挂 buff，属设计门控。实践依赖地牢结构生成与找到无名。

### 2.2 状态机与刷怪

| 阶段 | 条件（摘要） | 结论 |
| :--- | :--- | :---: |
| Phase1 | `!isDay && OVERWORLD && !intrude && brightness≤7 && rand<0.0005` | **PASS** |
| Phase2 | `intrude && !end && rand<0.02` + y+2/y+1 空、y-1 实心 | **PASS**（地形依赖） |
| Phase3 夜清剿 | `end && intrude && 无 WeakenessTerrorbeak in ofSize(32)` | **PASS** |
| 白天强制 | `isDay && intrude`（任意维度，只要 tick 在跑） | **PASS** |

实体：`PDEntities.WEAKENESS_TERRORBEAK` / `SHADOW_HAND` 已注册；`MobSpawnType.MOB_SUMMONED` 可生成。

**已知边角（均 PARITY 或低严重度）**

| # | 项 | 严重度 | 说明 |

### 2.3 平息、成就、Stage 衔接

| 项 | 状态 | 证据 |
| :--- | :---: | :--- |
| calm 清 flag + 平息文案 | **PASS** | `PDEffects.java:1387-1392` |
| 授 `achievement_shadow_npc_3` | **PASS** | impossible 触发；剩余 criteria 全 award；JSON 存在、无 display（隐藏节点） |
| 唯一生产授予点 | **PASS** | 生产 grep：仅 calm；Stage **不**直接授 npc_3（符合文档 §6.2） |
| 首次 remove spyon | **PASS** / **PARITY** | 在 `!isAdvancementDone(npc_3)` 块内；重复 calm 只清 flag + 平息句 |
| Stage4 门控 | **PASS** | `done3 && !done4` → `startStage4`（`ShadowNpc0Entity:162-164`） |

| 字段 | 原版 | Neo | 差 |

**对等总判：可正常进行。**

### 2.5 VERIFY 覆盖

| 套件 | 角色 | 在 all？ |
| :--- | :--- | :---: |
| **`shadow-intrude`**（2026-07-30 新增） | 入侵专项：门控 / 牛奶 / 白天·清剿 calm / spawn 实体 / Stage4 / 重复 calm；实测 **30/0** | **否** |
| `main-flow` | 全链路内嵌确定性 calm→npc_3 + 后续 Stage4/5… | **否** |
| `second-dream` | 竞技场胜利移除 spyon 等，无入侵状态机 | **否** |

**`shadow-intrude` 断言矩阵**（`PDShadowIntrudeVerifyHooks`）

| 点 | 覆盖 | 方式 |
| :--- | :--- | :--- |
| 注册 | 效果/实体/音效/维/成就 JSON | 静态 |
| 离灯影挂 buff | 无 npc_2 不挂；npc_2&&!e_0 挂≈32000；e_0 不挂 | 真派发 `PlayerChangedDimensionEvent` |
| 牛奶不可清 | `getCures().isEmpty()` | addEffect 后查 |
| 白天 calm→npc_3 | forceDay + 泵 `applyEffectTick` | **禁止 grant npc_3** |
| 清剿阻挡 | 刷尖喙 → 仍 intrude；discard → calm | 真实体 + 夜间 end |
| MOB_SUMMONED | terrorbeak + hand 可生成 | spawn 后 discard |
| Stage4 | npc_3 后真 `mobInteract`→npc_4 | advance ~560t |
| 重复 calm | 已 npc_3：flag 清、**不** remove buff | 原版语义 |

Phase1 `0.0005` / Phase2 `0.02` 随机**仍不赌**（确定性写 flag）。

```bash
PASTERDREAM_VERIFY=1 PASTERDREAM_VERIFY_SUITES=shadow-intrude \
  PASTERDREAM_VERIFY_KEEP_OPEN=0 \
  JAVA_HOME=/usr/lib/jvm/java-21-openjdk \
  sh gradlew :PasterDream:runClient --offline
```

IDE：`.run/PD VERIFY shadow-intrude.run.xml`

**main-flow 采信**（既有）：dark/light 近次 **58/0**；`continuousFlags.npc_3=true`。

**VERIFY 能证明什么**

- ✅ 生产 tick 在 flags+白天/清剿条件下可走 calm → 真授 npc_3  
- ✅ buff 授予门控与不可奶、Stage4 衔接、重复 calm 语义  
- ✅ 入侵用实体可 `MOB_SUMMONED`  
- ❌ 仍不证明「夜暗低概率触发 → 地形刷怪循环」的自然端到端（手测/可选增强）
