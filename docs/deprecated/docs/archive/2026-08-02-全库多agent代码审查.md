## 2. 按严重度汇总（已抽查）

### Critical

#### C1. 音乐碟物品硬 import 客户端 `Screen`（Dedicated Server 类加载风险）

| 项 | 内容 |
| :--- | :--- |
| 文件 | `item/PastedreamMusicDiscItem.java:3,85` |
| 失败场景 | Dedicated Server 加载物品类时解析 `net.minecraft.client.gui.screens.Screen` → **NoClassDefFoundError / 启动失败**。即使 tooltip 仅客户端触发，顶层 import 已污染类依赖图。 |
| 证据 | `import net.minecraft.client.gui.screens.Screen;` + `if (Screen.hasShiftDown())` 位于 common `Item` 子类。`item/` 下仅此文件硬 import client（翅膀已反射隔离）。 |
| 修复 | 移除 client import；Shift 判断改客户端 tooltip 扩展 / `@OnlyIn` 代理 / 始终展示元数据；保证 DS 可加载该类 |

#### C2. Sculk / Titanium / Dyedream 盔甲非满套 `removeEffect` 剥离外来同名 buff

| 项 | 内容 |
| :--- | :--- |
| 文件 | `item/SculkArmorItem.java:40-45` · `TitaniumArmorItem.java:40-45` · `DyedreamArmorItem.java:40-49` |
| 失败场景 | 玩家持有药水/信标/其他来源的隐身、夜视或生命提升时，穿/脱一件对应盔甲（或未满套）→ 每 tick `inventoryTick`（×最多 4 件）执行 `removeEffect` → **外来效果被立刻剥掉**。 |
| 证据 | `if (hasFullSet) addEffect(...); else entity.removeEffect(INVISIBILITY|NIGHT_VISION|HEALTH_BOOST);`；仅 `!client` 守卫。对照 `QymArmorItem` 已改为「仅 add 短时效、不 remove」。 |
| 修复 | 仅满套时 refresh 短 duration 并自然过期；**禁止** `removeEffect`；逻辑集中到单件（如头盔） |

## 5. 建议修复优先级

1. **立刻（DS/启动）**：C1 音乐碟去掉 client import。  
2. **玩法破坏**：C2 三套盔甲禁止 `removeEffect`。  
3. **多人/世界**：H2 地牢清场收窄；H3 关键 schedule 持久化或 on-load 恢复；H4 biome seed；H5 fillbiome gamerule try/finally。  
4. **工程可信度**：H1 VERIFY 真路径驱动，减少 soft accept。  
5. **一致性**：M1/M2 creative 消耗；M3 感染判定；M4 能量 enabled；M5 fat/thin 互斥；M6 gallery 默认排除。

**回归建议**：

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk sh gradlew :PasterDream:runServer --offline
# 以及
PASTERDREAM_VERIFY=1 PASTERDREAM_VERIFY_SUITES=quick,behavior \
  JAVA_HOME=/usr/lib/jvm/java-21-openjdk sh gradlew :PasterDream:runClient --offline
```

重点手测：DS 启动加载音乐碟；Sculk/钛/染梦盔甲 + 隐身/夜视药水；地牢生成旁掉落物/马；新档染梦河流是否随种子变；无 playeranimator 正式包闪避；fat 单包与 fat+thin 混装。
