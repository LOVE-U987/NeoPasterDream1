# Issue 11审计报告

1. 染梦睡莲在水下看时不渲染莲叶。同时睡莲类植物无法像原版一样立即破坏。船也会被阻挡。

3. 不同大小的染梦晶芽掉落数量都是一个晶芽粒。晶芽粒还查不到获取方式（有EMI Loot可以查看方块掉落，但查不到）
