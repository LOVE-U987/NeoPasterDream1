## 0. 一句话

**染梦**：裂隙笔记 → 染梦世界笔记（`a_0`→`b_0`）→ 染梦 **萦风教堂** `dream_church_10` 取 **`dreamnotes_14`** 读出 **`hide_16`**。  
**主世界**：做并吃 **奇异炖菜** 挂 **迷梦** → 飞到 **Y≥306**（云雾 HUD 自 Y>260 起涨）→ 进 **风之旅途**（坐标 XY 不变）。  
**风维内**：采 **风行者水晶 / 凝结之风**、做 **凝风铁锭**、梦境炼药釜炼 **闪电法术** → 找 **失落风骑士遗迹** 祭坛 → 水晶 + 三锭 + 闪电唤醒 **风之骑士** → 击杀掉 **脉冲风行者水晶**（原版表）。  
**离开**：掉到风维 **Y≤5**（需 **云雾** 效果 tick）→ 回主世界重生点/出生点 **XZ、Y=304**。

## 2. 如何进入风之旅途

实现：`PDEffects.fondillusionTick` ← 原 `FondillusionBuffPr0Procedure`。

### 2.1 条件（须同时）

1. 维度 = **主世界** `Level.OVERWORLD`  
2. 实体为玩家，且持有 **`fondillusion_buff`**（效果 onTick）  
3. **`Y > 260` 且 `Y ≤ 310`**：写入 `cloudmist_percent = (Y - 260) * 2`（HUD）  
4. **`Y ≥ 306`**  
5. 已完成 **`achievement_b_0`** 与 **`achievement_hide_16`**  
6. 目标维 `server.getLevel(wind_journey_world) != null`，且当前不在该维  

失败时：高度不够只涨云雾；缺成就则飞到顶也不会传（无聊天提示，静默）。

### 2.2 传送结果

| 项 | 值 |
| :--- | :--- |
| 目标维 | `pasterdream:wind_journey_world` |
| 落点 | **同一 X/Y/Z** 与 yaw/pitch（原版 `teleportTo(nextLevel, x,y,z,…)`） |
| 包序列 | 原版：`WIN_GAME` + 能力/效果同步 + 维度事件 **1032**；Neo：`ServerPlayer.teleportTo(ServerLevel,…)` 等价 |

### 2.3 进维瞬间（原版 / Neo）

原版 `WindJourneyWorldDimension` @ `PlayerChangedDimensionEvent` → `WindJourneyWorldPr0`：

- 聊天：`§4本主题梦境尚未完工`  
- 音效：`pasterdream:wind_journey`（MUSIC）

Neo：`PlayerDataEvents.onPlayerChangedDimension` **仅**同步 San / 融梦能量；**未**接进维 title/音乐过程（见 §10）。

### 2.4 云雾 HUD（进维前）

客户端 `CloudmistHudOverlay`：主世界 + **迷梦** 时，在 260&lt;Y≤310 按同一公式本地重算浓度；全屏 `cloudmist_hud.png`。

## 3. 离开风之旅途

实现：`PDEffects.cloudmistTick` ← 原 `CloudmistBuffPr0Procedure`。  
**出维依赖 `cloudmist_buff` 正在 tick**，不是「只要掉虚空」。

### 3.1 条件

| 项 | 值 |
| :--- | :--- |
| 维度 | `wind_journey_world` |
| 效果 | 持有 **`cloudmist_buff`** |
| 浓度带 | `0 < Y ≤ 50` → `cloudmist_percent = (50 - Y) * 2` |
| 传送阈值 | **`Y ≤ 5`** |

### 3.2 落点

1. 先 `teleportTo` **主世界**，暂用当前 X/Y/Z  
2. 再瞬移到：  
   - X/Z = 玩家 **重生点**（若重生维=当前主世界且位置非空），否则 **世界出生点** X/Z  
   - **Y = 304**（固定高空）

图鉴：「掉入风之旅途世界的虚空，即可返回主世界的高空。」与代码 Y≤5 一致（维度 `min_y=0`，低空即云海/虚空带）。

### 3.3 云雾效果从哪来（关键）

| 来源 | 原版 | Neo |
| :--- | :--- | :--- |
| 风维环境 | `SanHelper`：在 `wind_journey_world` 时每 tick 挂 **`cloudmist_buff` 200t**，且环境 San 变化 **+1.2** | **未找到**等价「在风维自动挂云雾 / +1.2 San」接线 |
| 其它 | 剑气等误用云雾作寿命标记（`TerraswordWave`） | 同，与出维无关 |

**后果（Neo）**：若玩家在风维 **没有** `cloudmist_buff`，掉到 Y≤5 **不会**触发返程——需命令给效果、或待环境 San 钩子补齐。原版生存链路靠 SanHelper 自动续云雾。

其它离开：`/execute in minecraft:overworld …`、死亡（床可用：`bed_works=true`）等，非流程设计出口。

## 7. Boss 战：风之骑士（wind_knight）

显示名：`§b风之骑士`（lang）。玩法文档与祭坛中文「破风骑士」指同一条唤醒线。

### 7.1 属性

| 属性 | 值 |
| :--- | :--- |
| 生命 | **150** |
| 护甲 | 10 |
| 攻击 | 20 |
| 移速 | 0.25 |
| 跟随 | 16 |
| 击退抗 | 0.4 |
| XP | 32 |
| 体型缩放（原版） | ×1.6 |
| 免疫 | 火焰 / 熔岩 / 坠落（Neo 另显式 `IN_FIRE`/`ON_FIRE`/`LAVA`/`FALL`） |

AI：近战（1.25 速）· 复仇 · 索敌玩家 · 闲逛。音效：铁傀儡步进/受伤/死亡。

### 7.2 技能（原版 vs Neo）

**原版 `WindKnightPr0`（每 tick）：**

- 持久数据 `time`：&lt;180 则 +1；≥180 且 11 格内有玩家：  
  - 动画 `skill_0`  
  - 自身缓慢 IV 20t  
  - 5t 铁傀儡受伤音  
  - **25t 后**：半径约 **6** 格内非 `special_entity_tag`、非自身 → **30** 点 `mob_attack`；爆炸/云/暴击粒子；技能音 + 爆炸音；自身速度 I 20t  
  - `time` 归 0  
- 每 tick `clearFire`

**Neo `WindKnightEntity.serverAoeTick`（简化）：**

- 冷却 **300t（15s）**（非原版 180t 充能）  
- 最近玩家距离 ≤10 且视线：立刻技能音；半径 **4** 内 **12** 伤害；自身速度 200t + 缓慢 II 100t  
- **无**原版 25t 前摇、30 伤、粒子爆发与 `time` 计数  

以现仓库 Neo 实体为准打手感；对照原版改数值时改 `WindKnightEntity`。

## 8. 风向子系统（探索辅助）

| 部件 | 作用 |
| :--- | :--- |
| 游戏规则 `pasterdreamWindDirection`（0–7） | 北 / 东北 / 东 / … / 西北 |
| 原版 `WindDirectionPr0` | 风维内 **`dayTime % 24000 == 0`** 时随机 0–7，并广播「朝阳升起… 呼啸的风正吹往 §a某方向」 |
| 原版 `WindDirectionPr1` | 面朝风向锥形 → 短 **顺风** `tailwind_buff` |
| 原版 `WindDirectionPr2` | **未**装备破风旗帜时的逆风侧逻辑 / 与旗帜配合把逆当顺（见原版条件） |
| `wind_vane` 风向标 | 右键：俯仰/偏航 +「当前风向：§a×风」；读 gamerule |
| Neo | **gamerule + 风向标 + 顺风/逆风效果注册在**；**未找到** Pr0 日更 / Pr1·Pr2 每 tick 施加的移植入口 |

风车小屋结构含 `wind_vane` 实体展示/掉落物，便于找到标。
