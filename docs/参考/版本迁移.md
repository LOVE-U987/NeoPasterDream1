# 版本迁移

> 本文档提供 1.20.1 Forge → 1.21.1 NeoForge 的 API 迁移对照。

---

## API 变更映射

| 1.20.1 Forge | 1.21.1 NeoForge | 说明 |
|-------------|----------------|------|
| `forge:` | `neoforge:` 或 `c:` | 命名空间变更 |
| `forge/tags/items/` | `c/tags/item/` | 标签路径变更 |
| `forge:fluid_container` | `neoforge:fluid_container` | 流体容器变更 |
| `Capability` + `IStorage` | **Attachment** | 机制重写 |
| `ArmorItem#onArmorTick` | **已移除** | 改用 `Item#inventoryTick` + `EquipmentSlot` |
| `MCreator.queueServerWork` | `ServerScheduler` | 定时任务重写 |
| `SimpleChannel` + `IMessage` | **Payloads** | 网络包简化 |
| `RandomizableContainerBE` | `BlockEntity` + `ItemStackHandler` | 容器重写 |
| `DeferredWorkQueue` | 构造 / 事件注册 | 延迟注册变更 |

## 注册变更

### DeferredRegister

```java
// 1.20.1 Forge
DeferredRegister<Block> register = DeferredRegister.create(ForgeRegistries.BLOCKS, MOD_ID);

// 1.21.1 NeoForge
DeferredRegister<Block> register = DeferredRegister.create(Registries.BLOCK, MOD_ID);
```

```java
// 1.20.1 Forge

ForgeRegistries.ITEMS
ForgeRegistries.ENTITY_TYPES

// 1.21.1 NeoForge
Registries.BLOCK
Registries.ITEM
Registries.ENTITY_TYPE
```

## 网络变更

### Payload 定义

```java
// 1.20.1 Forge
public class MyMessage implements IMessage {
    @Override
    public void fromBytes(ByteBuf buf) { }
    
    @Override
    public void toBytes(ByteBuf buf) { }
    
    public static class Handler implements IMessageHandler<MyMessage, IMessage> {
        @Override
        public IMessage onMessage(MyMessage message, MessageContext ctx) {
            return null;
        }
    }
}

// 1.21.1 NeoForge
public record MyPayload(int data) implements CustomPacketPayload {
    public static final CustomPacketPayload.Type<MyPayload> TYPE = 
        new CustomPacketPayload.Type<>(ResourceLocation.fromNamespaceAndPath(MOD_ID, "my_payload"));
    
    public static final StreamCodec<ByteBuf, MyPayload> STREAM_CODEC = 
        StreamCodec.composite(
            ByteBufCodecs.INT,
            MyPayload::data,
            MyPayload::new
        );
    
    @Override
    public Type<? extends CustomPacketPayload> type() {
        return TYPE;
    }
    
    public static void handle(MyPayload payload, IPayloadContext context) {
        context.enqueueWork(() -> {
            // 处理逻辑
        });
    }
}
```

### 网络注册

```java
// 1.20.1 Forge
INSTANCE.registerMessage(0, MyMessage.class, MyMessage::toBytes, MyMessage::fromBytes, MyMessage.Handler::onMessage);

// 1.21.1 NeoForge
PayloadRegistrar registrar = INSTANCE.registrar("1");
registrar.playToClient(MyPayload.TYPE, MyPayload.STREAM_CODEC, MyPayload::handle);
```

## 容器变更

### BlockEntity 容器

```java
// 1.20.1 Forge
public class MyBlockEntity extends RandomizableContainerBE {
    private final NonNullList<ItemStack> items = NonNullList.withSize(27, ItemStack.EMPTY);
    
    @Override
    public Component getDisplayName() {
        return Component.translatable("container.my_block");
    }
    
    @Override
    protected Component getDefaultName() {
        return Component.translatable("container.my_block");
    }
    
    @Override
    protected AbstractContainerMenu createMenu(int id, Inventory player) {
        return new MyMenu(id, player, this);
    }
    
    @Override
    public int getContainerSize() {
        return 27;
    }
    
    @Override
    protected ItemStack getItem(int index) {
        return items.get(index);
    }
    
    @Override
    protected void setItem(int index, ItemStack stack) {
        items.set(index, stack);
    }
}

// 1.21.1 NeoForge
public class MyBlockEntity extends BlockEntity implements MenuProvider {
    private final ItemStackHandler itemHandler = new ItemStackHandler(27) {
        @Override
        protected void onContentsChanged(int slot) {
            setChanged();
        }
    };
    
    @Override
    public Component getDisplayName() {
        return Component.translatable("container.my_block");
    }
    
    @Override
    public AbstractContainerMenu createMenu(int id, Inventory player, Entity entity) {
        return new MyMenu(id, player, this);
    }
    
    public ItemStackHandler getItemHandler() {
        return itemHandler;
    }
}
```

## 能力变更

### 数据附件

```java
// 1.20.1 Forge
public class MyCapability implements ICapabilityProvider {
    @Override
    public <T> LazyOptional<T> getCapability(Capability<T> cap, @Nullable Direction side) {
        if (cap == MyCapability.CAPABILITY) {
            return LazyOptional.of(() -> this).cast();
        }
        return LazyOptional.empty();
    }
}

// 1.21.1 NeoForge
public class MyData {
    public static final Codec<MyData> CODEC = RecordCodecBuilder.create(instance -> instance.group(
        Codec.INT.fieldOf("value").forGetter(MyData::value)
    ).apply(instance, MyData::new));
    
    private final int value;
    
    public MyData(int value) {
        this.value = value;
    }
    
    public int value() {
        return value;
    }
}

// 注册
public static final DeferredAttachmentType<MyData> MY_DATA = 
    ATTACHMENT_TYPES.register("my_data", () -> AttachmentType.<MyData>builder()
        .serialize(MyData.CODEC)
        .build());

// 使用
MyData data = player.getData(PDPlayerAttachments.MY_DATA);
```

## 实体变更

### 属性注册

```java
// 1.20.1 Forge
@SubscribeEvent
public static void onEntityAttributeCreation(EntityAttributeCreationEvent event) {
    event.put(PDEntities.MY_ENTITY.get(), MyEntity.createAttributes().build());

    .entityClass(MyEntity.class)
    .attributes(MyEntity::createAttributes)
    .build();
```

```java
// 1.20.1 Forge

// 同上,但使用 NeoForge 的事件系统
@SubscribeEvent
public static void onEntityRenderers(EntityRenderersEvent.RegisterRenderers event) {
    event.registerEntityRenderer(PDEntities.MY_ENTITY, MyEntityRenderer::new);
}
```

## 常见迁移问题

### Q: 找不到 `forge:` 命名空间?

将 `forge:` 替换为 `neoforge:` 或 `c:`:

```java
// 1.20.1 Forge
ResourceLocation.fromNamespaceAndPath("forge", "ingots/iron");

// 1.21.1 NeoForge
ResourceLocation.fromNamespaceAndPath("c", "ingots/iron");
```

### Q: `Capability` 代码如何迁移?

使用 Attachment:

```java
// 1.20.1 Forge
LazyOptional<MyCapability> cap = entity.getCapability(MyCapability.CAPABILITY);

// 1.21.1 NeoForge
MyData data = entity.getData(PDPlayerAttachments.MY_DATA);
```

### Q: `queueServerWork` 如何迁移?

使用 `ServerScheduler`:

```java
// 1.20.1 Forge
queueServerWork(20, () -> { /* ... */ });

// 1.21.1 NeoForge
ServerScheduler.schedule(20, () -> { /* ... */ });
```
