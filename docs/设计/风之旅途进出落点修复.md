# 风之旅途进/出落点高度与返回方式修复

> 问题编号：P0-3（静态排查）
> 关联代码：`registry/PDEffects.java`（fondillusionTick / cloudmistTick）、`world/WindJourneyEvents.java`、`item/PaleBoneneedleItem.java`、`item/RootsPaleBoneneedleItem.java`
> 关联数据：`data/pasterdream/dimension_type/wind_journey_world.json`、`data/pasterdream/worldgen/noise_settings/wind_journey_world.json`
> 记录日期：2026-11-03　状态：已实现

## 1. 问题背景

原版（MCreator 生成）在风之旅途的进出维落点处理上存在致命坠落缺陷，移植版忠实还原了该缺陷：

| 环节 | 原版/移植现状 | 后果 |
|------|--------------|------|
| 进维（迷梦 buff Y>=306） | Y clamp 到 254 后原样传送，风维地形仅 Y 0~128 | 从 254 坠落 126+ 格，无缓降必摔死 |
| 跌破云层（风维 Y<=5） | 固定传回主世界 `y=304` | 坠落约 270 格，必死 |
| 虚空兜底（风维 Y<-10） | 固定传回主世界 `y=304` | 同上 |
| 骨针返回 | 白名单仅染梦/灯影/竞技场三维度（原版 `PaleBoneneedlePr0` 同） | 风维无任何主动返回手段 |

设计发现：`cloudmist_percent = (50 - Y) * 2` 的 HUD 递变（Y 50 -> 0）表明"从高空降入云海"是预期的进场体验，修复方向为"保留降落体验 + 防致命坠落"，而非改为直接落地表。

## 2. 修复方案

### 2.1 进维缓降保护（WindJourneyEvents.onPlayerTick）

风维内每 tick 检查：玩家（非创造/旁观）高于脚下地表（`MOTION_BLOCKING` heightmap）8 格以上时，若缓降缺失或剩余 <1s，补刷 3s 缓降（ambient、无粒子）。

- 进维（254 高空）后第一个 tick 即生效，覆盖全程降落；
- 出云层落地后自动停止补刷，效果约 3s 内耗尽，不残留；
- 相比"进维一次性给长时长"，该机制同时覆盖岛间失足，且不会在落地后长时间残留缓降。

### 2.2 返回主世界安全落点（WindJourneyEvents.returnToOverworldSafe）

统一公共 helper：优先玩家重生点（重生维为主世界时），否则世界出生点，取 XZ 处主世界 `MOTION_BLOCKING` heightmap 地表 Y 传送。替代固定 `y=304`。

调用点：

- `PDEffects.cloudmistTick`：跌破云层（Y<=5）返主世界（ServerPlayer 分支）；非玩家实体分支改落风维 (0,0) 地表 heightmap；
- `WindJourneyEvents.onPlayerTick`：虚空兜底（原 `voidFallbackToOverworld` 并入）。

### 2.3 骨针维度白名单扩展（有意差异）

- `PaleBoneneedleItem.isPasterDreamDimension` / `RootsPaleBoneneedleItem.isPasterDreamDimension` 补入 `wind_journey_world`；
- 理由：原版风维无任何主动返回手段（仅能靠跌破云层被动返回），且本修复后跌破云层通道已安全，补充主动返回手段属体验补强。

### 2.4 溯源骨针标记维度校验（移植补强）

白名单扩展引入新边界：在风维（Y 0~128）内设置的标记直接套用到主世界可能落进地形/虚空。处理：

- `useOn` 记录标记时附带维度 ID（`dim`）；
- `use` 返回时非主世界标记降级为重生点返回；
- 旧存档标记无维度记录（空串）按主世界处理，保持兼容。

## 3. 有意差异与说明

| 差异 | 相对原版 | 理由 |
|------|---------|------|
| 风维高空缓降补刷 | 原版无 | 原版进维/失足摔死，属缺陷修复 |
| 返回主世界 heightmap 落点 | 原版固定 y=304 | 同上 |
| 骨针白名单含风之旅途 | 原版仅三维度 | 风维原无主动返回手段 |
| 溯源骨针标记维度校验 | 原版无维度记录 | 白名单扩展引入的边界防护 |
