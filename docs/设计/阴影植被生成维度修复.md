# 阴影植被生成维度修复

日期：2026-11-08。

## 问题与根因

用户反馈影茎蕨（`grass_10`）、影蕨（`grass_11/12`）、阴影菌丝（`grass_8/9`）等植被生成在错误维度，应生成于灯影之下（lamp_shadow_world）。

对照原模组（`libs/FixPasterDream-main/`，只读）确认两层根因：

1. 本项目 `neoforge/biome_modifier/dyedream_vegetation.json` 把 `grass_8~12` 注入了染梦标签 `#pasterdream:is_dyedream`。原模组中这五个方块各自的 biome modifier 只指向 `biome_shadow_1`，染梦侧没有任何注入（全目录检索证实），属于移植时并档引入的错误。
2. 本项目不存在任何指向 shadow 系群系的 biome modifier，因此即使删除错误注入，这些植被在灯影之下也不会生成。`shadow_fungus`（阴影蘑菇）同源：placed/configured feature 与原模组一致，但原模组的 `shadow_fungus_biome_modifier.json`（指向 biome_shadow_1）漏移植，野生阴影蘑菇完全不生成。

维度群系映射依据：原模组 lamp_shadow_world 使用 `biome_shadow_0/1/2`，本项目重命名为 `shadow_wastes`/`shadow_forest`/`shadow_barrens`；`biome_shadow_1` 与 `shadow_forest` 的温度/湿度、六项效果颜色（-13684945）、环境音与音乐完全一致，刷怪列表为其超集（black_beetle 参数逐项相同），且 `biome_shadow_*` 在本项目 data 下已无任何引用。

## 修复内容

- `neoforge/biome_modifier/dyedream_vegetation.json`：删除 `grass_8~12` 五项，其余 20 项染梦植被注入不动。
- `worldgen/placed_feature/grass_8~12.json`（5 个文件）：`matching_blocks` 地面谓词在原 4 项染梦方块后追加 `pasterdream:shadow_nylium`。原模组无谓词；谓词保留并放开新落脚面，灯影之下地表由维度 surface rule 生成 `shadow_nylium`，满足 `offset [0,-1,0]` 检查。
- 新建 `neoforge/biome_modifier/shadow_vegetation.json`：`neoforge:add_features`，`biomes` 为 `pasterdream:shadow_forest`（对齐原模组仅 biome_shadow_1 的范围），`features` 为 `grass_8~12` 加 `shadow_fungus`，`step` 为 `vegetal_decoration`。

存活链验证：`grass_8/9/11/12`（`DyedreamFlowerBlock`）与 `grass_10`（`DyedreamDoublePlantBlock`）的 `mayPlaceOn` 检查 `pasterdream:plantable_on` 标签，该标签含 `#minecraft:dirt`，而 `shadow_nylium` 已在 `minecraft:dirt` 方块标签内，故可在阴影菌丝上存活与生成。

## 边界说明

- 不改 `shadow_fungus` 的 placed/configured feature：与原模组逐字段一致，其 placed feature 无地面谓词为原模组既有行为（理论上存在浮空蘑菇可能），不作为本次修复内容。
- 不新建 `is_shadow` 群系标签：单群系直接引用与原模组一致。
- 创造模式物品栏归置、灯影化感染（`ArenaInfectionUtils`）与野生生成无关，均不动。
