# 融梦水晶箱战利品设计

> 关联实现：`PasterDream/.../block/MeltdreamChestBlock.java`、`config/MeltdreamChestLootConfig.java`、`config/MeltdreamChestLootConfigMigration.java`
> 关联资源：`data/pasterdream/loot_table/chests/loots_meltdream_chest_0.json` / `_1.json`
> 记录日期：2026-09-25

## 1. 背景

原版融梦水晶箱的战利品完全由战利品表 `loots_meltdream_chest_0`（染梦）/`loots_meltdream_chest_1`（风旅/灯影）决定，包含 4 条独立池：材料 / 宝石 / **饰品** / 装备。移植版曾弃用该表、改为「3 品质手写配置池」，导致原版饰品池的 11 件饰品缺失（仅剩万象神戒与啵啵鸡的华丽飞羽可开出）。

本设计将默认掉落改回原版战利品表，并把三品质配置池降级为可选覆盖，同时保留移植版的附加内容（唱片/玩偶/水晶/纪念品）。

## 2. 三层解析

开箱时先 `selectQuality(random)` 决定品质（仅用于动画/音效与附加档位），随后按以下优先级填充：

1. **自定义开关开启**（`meltdream chest custom loot enabled = true`）
   - 解析玩家配置池（逐条容错：非法条目跳过，数量/权重钳制）
   - 池非空 → 使用玩家配置；空或全无效 → 回退隐藏内置默认池（记警告）
2. **开关关闭（默认）且维度为梦境**
   - 染梦 → `loots_meltdream_chest_0`；风旅/灯影 → `loots_meltdream_chest_1`
   - 表存在且非 `LootTable.EMPTY` → 基础填充 + 品质附加
   - 表缺失/无效 → 回退隐藏内置默认池（记警告）
3. **非梦境维度** → 回退隐藏内置默认池

隐藏内置默认池由 `MeltdreamChestLootConfig.DEFAULT_*` 提供，按原版四池重映射为三档（common=材料，rare=宝石+饰品，legendary=装备+顶级件），不出现在 toml/GUI。

## 3. 确定槽位算法（默认战利品表路径）

基础填充（`fillFromLootTable`）：

- 以 `LootContextParamSets.CHEST` + `ORIGIN` + `withLuck` + `THIS_ENTITY` 取 `getRandomItems`
- 过滤空栈，`n = min(base.size(), 8)`（预留 slot 8 作水晶位），顺序写入 `slot 0..n-1`，清空 `n..8`
- 内置表池结构为 rolls `1 / 1-2 / 1 / 1`，池 4 的 `tabitem_1`（count 0）过滤后 `n ≤ 4`，故 slot 8 恒空
- 数据包把表改为超 8 件时截断并记警告

品质附加（`applyQualityExtras`）：

| 品质 | 算法 |
|------|------|
| 1 普通 | 无 |
| 2 稀有 | `n>0` 时基础整体后移 1 位；slot 0 放唱片；50% 玩偶放首个空槽 |
| 3 传说 | `n≥2` 时随机替换一个基础槽为玩偶（保留至少一件）；`n<2` 时玩偶放空槽；最后写 slot 8 融梦水晶碎片 |
| 2/3 纪念品 | 约 10% 概率放首个空槽（`memento_item_03`/`08` 随机） |

边界：`firstEmptySlot < 0` 跳过；`n=0` 不触发 `nextInt(0)`；玩偶候选不含 slot 8；`_1`（`n=1`）传说档不替换唯一基础件。

## 4. 维度映射与有意差异

| 维度 | 表 |
|------|----|
| 染梦世界 `dyedream_world` | `loots_meltdream_chest_0` |
| 风之旅途 `wind_journey_world` | `loots_meltdream_chest_1` |
| 灯影世界 `lamp_shadow_world` | `loots_meltdream_chest_1` |
| 其它 | 隐藏内置默认池 |

与 PasterDream 原版的差异（有意）：

- 原版品质（Pr1/Pr2/Pr3）同时决定动画/音效与部分维度的取表分支（Pr1：染梦/风旅；Pr2、Pr3：染梦/灯影）；本实现统一按维度取表，品质不再影响取表。
- 非梦境维度原版不挂表（无掉落），本实现回退隐藏默认池。此为兼容旧移植行为的保守选择，**不构成防刷**（稀有档兜底池亦含 11 件饰品）；如需严格防刷可改为其它维度无掉落。
- 默认路径附加唱片/玩偶/水晶/纪念品为移植版扩展，原版战利品表不含。

## 5. 配置与迁移

- 三个品质物品池默认值改为空列表；内置池转为隐藏常量。
- 一次性迁移 `MeltdreamChestLootConfigMigration`：挂 `ModConfigEvent.Loading`（1.21.1 起 `EventBusSubscriber.bus()` 被忽略，事件总线按 `IModBusEvent` 自动判定）。仅当配置值逐条等于旧内置默认时清空，玩家自定义保留；以 TomlWriter 直写落盘（不调用 `ILoadedConfig.save()`，规避 `Reloading` 副作用）。

## 6. 验证要点

- `:PasterDream:compileJava` 通过
- 新战利品表 JSON 可解析，`_0` 含 11 件饰品 ID，`_1` 含 `cyan_moss_stone`
- 固定 seed 反复 roll 可命中全部 11 件饰品
- 传说档 slot 8 恒为融梦水晶碎片；玩偶不落 slot 8；稀有档 slot 0 为唱片
- 空池/满格/数据包超 8 件不崩溃
- 迁移对旧默认清空、对自定义保留
