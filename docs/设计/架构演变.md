## 3. 已识别演变项

### 3.1 api.doll 上收候选

- **现状**：`api.doll` 包（5 类）包名属 `api.*` 命名空间，物理位于主模（历史遗留）；主模 10+ 处引用（方块/DataGen/KubeJS/创造栏）
- **方向**：符合[API 边界](../参考/API边界.md)三零判定时迁移至 PasterDreamAPI 模块，主模薄壳保留兼容
- **注意**：迁移前不得模仿此模式新增代码（见[API 架构详解](../架构/API架构详解.md) 4.7）

### 3.2 spell 预留包取舍

- **现状**：API `spell` 包仅 `ISpell` + `SpellAPI` 两个接口类，当前无下游消费
- **方向**：二选一——随法术内容扩充实现（Spells 附属为消费方），或移除包避免死接口
- **判定时机**：下一个法术相关功能立项时

### 3.3 docs/deprecated/ 清理

- **现状**：旧版文档已全部移入 `docs/deprecated/`，规则禁止引用
- **方向**：择期整体移除（AGENTS.md 已注明"后续将被移除"）；有价值的数据已重生至 [开发进度](开发进度.md)
- **前置**：确认无外部链接指向 deprecated 路径

### 3.4 附属模块扩展

- **现状**：Spells 24 类（五法术闭环）、Sanity 5 类、MeltDream 6 类，均通过 API 配置接口接入
- **方向**：
  - Spells：新法术条目（卷轴/投射物/立场复用现有注册模式）
  - Sanity / MeltDream：数值规则调优，结构已稳定无需拆分
- **边界**：新附属立项前先过[模块边界](../架构/模块边界.md)归属决策

### 3.5 VFX 处理器扩展点

- **现状**：`EmitterProcessorRegistry` 已注册 4 个内置处理器（绑定实体/圆环/空/注册表）
- **方向**：新特效需求优先实现 `EmitterProcessor` 扩展而非硬编码新子系统；屏幕效果同理走 `ScreenEffectFactory`

### 3.6 dimension terrain 协商器完善

- **现状**：`TerrainRequirements` → `TerrainAssessment` → `TerrainAdjuster` → `StructureTerrainNegotiator` 链路已建立（[API 架构详解](../架构/API架构详解.md) 4.3）
- **方向**：接口可能随新维度结构需求调整，属演进中 API；新结构落位问题优先在此链路解决

### 3.7 API 独立发布

- **现状**：`maven-publish` 插件已配置，未发布到任何仓库；附属经 `implementation project(':PasterDreamAPI')` 编译
- **方向**：若未来需要第三方模组依赖 API，再评估发布渠道（Maven 仓库 / GitHub Packages）；当前不发布
