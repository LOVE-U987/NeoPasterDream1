# 星空枕重做实现方案

> 类型：附属实现文档（隶属 [星空枕玩法设计](星空枕玩法设计.md)）
> 状态：方案定稿，未实施
> 关联文档：[星空枕玩法设计](星空枕玩法设计.md)、[模块边界](../架构/模块边界.md)、[客户端服务端分离](../架构/客户端服务端分离.md)

---

## 1. 架构总览

- 服务端权威：星体布局、玩家链、奖励结算、跨日重置全部在服务端。
- 客户端职责：接收同步数据、渲染星体与连线、命中判定、发送请求包。
- 星体布局由世界种子确定性生成，全服一致；存档只保存玩家链等动态数据。
- 数据挂染梦维度，天然满足「不跨维度、不跨存档」。

---

## 2. 服务端数据（SavedData，挂染梦维度）

新增 `world/sky/SkyStarFieldData.java`，参照 `world/PortalInfectionData.java` 的
`SavedData.Factory` + `load` + `save` 模式。`ServerLevel.getDataStorage()` 按维度隔离，
数据落于染梦维度的 `data/` 目录。

| 字段 | 说明 | 是否入存档 |
|------|------|-----------|
| `List<SkyPoint> stars` | 由种子确定性生成，星数 = `SKYLINK_MAX_STARS` | 否（可重算） |
| `List<Constellation> constellations` | 生成时同步产出的星座簇（节点索引组 + 规范边集） | 否（可重算） |
| `Map<UUID, List<Integer>> chains` | 每玩家链式星序列（相邻对 = 边） | 是 |
| `Map<UUID, Integer> freeLinkDailyCount` | 本日自由连线已领奖次数 | 是 |
| `Map<UUID, Set<Integer>> completedConstellationIds` | 本日各玩家已完成的星座 ID | 是 |
| `int starCount` + `long starSeedSalt` | 生成参数，用于 load 校验 | 是 |
| `long lastDay` | 日序号（`dayTime / 24000`） | 是 |

**load 兼容**：过滤越界星索引；若存档生成参数（星数）与当前配置不符，重置 `chains`
以防索引错位。

## 3. 星体生成

新增 `world/sky/SkyStarGenerator.java`：

- 输入：`dyedreamLevel.getSeed()` + 固定 salt。
- 随机源：`LegacyRandomSource`，保证跨会话、跨玩家一致。
- 输出：星体球面坐标列表 + 星座簇（节点索引组 + 规范边集）。
- 坐标约定复用 `client/sky/render/SkyGeometry.point`（`point(yaw, pitch)`）。
- 星座图案参考 `PasterDreamAPI` 的 `SkyboxPresets` 星座形状思路（仅参考形状组织方式，不复用其渲染内容）。

---

## 4. 每日重置

- 以 `Math.floorDiv(serverLevel.getDayTime(), 24000L)` 计算 dayIndex，与 `lastDay` 比较，
  不一致即重置（参照 `world/WindJourneyEvents.java` 的 dayIndex 防重复写法）。
- 重置内容：清空 `chains` / `freeLinkDailyCount` / `completedConstellationIds`，更新 `lastDay`，
  广播 `SkyLinkResetPayload`。
- 补检时机（三处）：
  1. 染梦维度 `LevelTickEvent.Post`
  2. `PlayerEvent.PlayerLoggedInEvent`
  3. `PlayerEvent.PlayerChangedDimensionEvent`（进入染梦维度）
- 订阅接线：`PasterDreamMod` 构造器 `NeoForge.EVENT_BUS.addListener`，与现有事件一致。

## 5. 网络包

主模块 `network/` 下新增，注册进 `PDNetwork.registerPayloads`。codec 组合要点：
`UUIDUtil.STREAM_CODEC`、`ByteBufCodecs.collection(ArrayList::new, ByteBufCodecs.VAR_INT)`、
`ByteBufCodecs.map(HashMap::new, keyCodec, valueCodec)`。

| 包 | 方向 | 字段 |
|----|------|------|
| `SkyLinkSyncPayload` | S2C | 星体浮点列表 + 全服 chains + freeLinkDailyCount + completedConstellationIds + dayIndex |
| `SkyLinkAddPayload` | S2C | UUID + fromIdx + toIdx |
| `SkyLinkUndoPayload` | S2C | UUID + 被移除边(from, to) |
| `SkyLinkResetPayload` | S2C | dayIndex |
| `SkyLinkConnectPayload` | C2S | int starIndex |
| `SkyLinkUndoRequestPayload` | C2S | 无参（撤回本人最后一条连线） |

同步时机：玩家登录、进入染梦维度、连线变更（增量广播）、跨日重置（重置/全量包）。

## 7. 服务端处理与奖励

新增 `world/sky/SkyLinkHandler.java`：

- 校验：染梦维度 + 夜晚 + 手持星空枕 + 星索引合法。
- 连线：新星 == 链尾则忽略；否则追加生成一条边；`setDirty()` → 广播 `SkyLinkAddPayload`。
- 撤回：移除本人链尾边；不退还已发奖励、不递减 `freeLinkDailyCount`（防刷）。
- 结算：调用 `SkyLinkRewards`。
- 首次成功连线 → `PDAdvancements.award(player, "achievement_skylink")`。

新增 `world/sky/SkyLinkRewards.java`（可插拔钩子）：

- `onFreeLink(player, from, to)`：自由连线小额奖励；受每日限次控制。
- `onConstellationComplete(player, constellationId)`：星座大奖；记入 `completedConstellationIds`，同日不重复。

星座判定：玩家边集合包含某星座规范边集 → 触发大奖。

## 11. 验证与合规

- 编译：`.\gradlew :PasterDream:compileJava`（最低要求），必要时全量 `.\gradlew compileJava`。
- 数据生成：本次 lang / advancement 均为静态文件，无 datagen 变更，`runData` 非必需。
- 手动验收（`runClient`）：
  - 染梦夜晚右键星体连线成功、左键撤回成功；
  - 他人连线暗色显示、本人高亮；
  - 跨日重置；
  - 非染梦维度不显示、不可操作；
  - 羽星占卜图录联动仍生效；
  - 织星者成就首次连线授予。
- 合规：新文件 LF / UTF-8 无 BOM、4 空格、K&R、注释中文无 Emoji、单方法不超过 50 行、
  无硬编码、注册走 `DeferredRegister`、不触碰 `libs/`。
