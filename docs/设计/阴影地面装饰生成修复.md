# 阴影地面装饰生成修复

> 修复日期: 2026-11-08
> 问题编号: B3（阴影维度地面装饰全失）
> 状态: 已修复（数据包层面），runClient 目视验证待人工执行

## 一、问题

阴影维度地面装饰 `ground_feature_shadow_0..7` 的 placed/configured feature 文件齐全，
但缺少 `neoforge/biome_modifier` 注入，导致零挂载:

- 无熔融阴影湖（`ground_feature_shadow_0`，fluid=shadow_liquid，barrier=shadow_stone）
- 无巨型阴影菌（`ground_feature_shadow_1`，huge_fungus）
- 无石材侵蚀变体（`ground_feature_shadow_2/3/5/6`，netherrack_replace_blobs）
- 无阴影岩石堆（`ground_feature_shadow_4`，forest_rock）
- 无陶罐散布（`ground_feature_shadow_7`，random_patch clay_pot_0）

`PDBlocksShadow`（shadow_liquid 注册处）与 `ShadowLiquidFluid` 的类注释自称
"世界生成硬依赖：ground_feature_shadow_0 湖泊特征引用"，实际依赖链断裂。

注意: `shadow_fungus`（阴影蘑菇）不属此问题——已由 `shadow_vegetation.json` 挂载
`shadow_forest`（见《阴影植被生成维度修复》）。

## 二、修复方案

新建 3 个 biome modifier（`type: neoforge:add_features`，`step: surface_structures`），
按原模组 `biome_shadow_0/1/2` 到本项目 `shadow_wastes/forest/barrens` 的映射逐一还原
（映射依据见《阴影植被生成维度修复》L14）:

| 新文件 | 群系 | 特征 |
|--------|------|------|
| `shadow_ground_wastes.json` | shadow_wastes | ground_feature_shadow_0, _4 |
| `shadow_ground_forest.json` | shadow_forest | ground_feature_shadow_1 |
| `shadow_ground_barrens.json` | shadow_barrens | ground_feature_shadow_2, _3, _5, _6, _7 |

文件路径: `PasterDream/src/main/resources/data/pasterdream/neoforge/biome_modifier/`

### 设计约束

- **不可合并为单个 modifier**: placed feature 带 `minecraft:biome` placement，
  只判断"当前群系是否包含该 feature"。若将 8 个特征注入全部 3 个群系，
  每个群系都会尝试全部特征（如 shadow_forest 出现熔融阴影湖），改变原模组分布行为。
- features 数组按编号升序排列，保持同 step 内相对生成顺序。
- 原模组为 `forge:add_features`（1.20.1 旧命名），本项目为 `neoforge:add_features`（NeoForge 1.21.1）。
