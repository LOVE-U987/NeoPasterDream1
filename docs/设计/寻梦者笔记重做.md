# 寻梦者笔记系统重做

- 状态：已实现（P0–P3 + P4；已过 audit/guards 并修复其发现项；2026-10-13 交互重做见 §10）
- 分支：`dev/milestore/momonyako-alpha`
- 计划文件：`.opencode/plans/寻梦者笔记重做.md`（audit 后删除）
- 关联：`docs/架构/主模组架构详解.md`、`docs/参考/API边界.md`、`docs/架构/模块边界.md`

## 1. 背景

原 `dreamnotes_0..14` 为固定叙事页，正文烘焙在 `textures/screens/dreamnotes_guiN(_en).png`，
经 `dreamnotes_gui_0` 容器菜单展示。本重做改为**数据驱动正文 + Markdown 渲染 + 18 行/120px 自动分页**，
并新增**玩家可编辑双语笔记**，同时把研究台梯度改为数据驱动。

## 2. 架构

### 2.1 数据模型（同步动态注册表）

- `pasterdream:dreamnotes`：`NoteDefinition`（title/body 语言映射、unlock、required、
  locate_shadow_base、give、extra_messages）。目录 `data/<ns>/pasterdream/dreamnotes/<entry>.json`。
- `pasterdream:note_research`：`ResearchChain`（steps、completion、completion_exp）。
  目录 `data/<ns>/pasterdream/note_research/<entry>.json`。
- 均经 `DataPackRegistryEvent.NewRegistry` 注册并提供同步 codec，datapack 定义自动同步客户端。
- 注册与查询：`dreamnotes/PDNoteRegistry`、`dreamnotes/NoteDefinition`、`dreamnotes/ResearchChain`。

### 2.2 通用类（上收 PasterDreamAPI）

- `api/text/NoteText`：Markdown 子集（`*` 斜体 / `--` 删除线 / `__` 下划线 / `<name>`·`<#RRGGBB>` 颜色 /
  `\` 转义 / `§` 透传）转 `Component`（common）。
- `api/text/NoteLimits`：折行宽 120、每页 16 行（2026-10-13 由 18 调为 16，见 §10）、最多 128 页、正文 28000 字节（双端共用）。
- `api/client/text/NotePagination`：`@OnlyIn(CLIENT)` 的 `StringSplitter` 折行分页。

### 2.3 交互与网络

- 废弃 `dreamnotes_gui_0` 菜单，改 `OpenNotePayload`(S2C) + `SaveNotePayload`(C2S)。
- 客户端桥 `client/PDClientNoteScreens`（`PDNetwork` 经反射转发，避免 common 引用客户端）。
- 界面：`client/screen/DreamnoteScreen`（只读分页渲染）、`client/screen/DreamseekerNotesScreen`（编辑）。
  共用羊皮卷底图 `textures/screens/dreamnote_paper.png`，**无工具栏**。

### 2.4 物品与获取

- `dreamnotes_0..14` 保留注册名，统一 `item/DreamnotesItem`（数据驱动，右键下发打开包）。
- 新增可编辑物品 `dreamseeker_notes`（`item/DreamseekerNotesItem`，`CUSTOM_DATA` 双语字段），
  可合成（纸 + 墨囊）。
- 研究台 `block/entity/ResearchTableBlockEntity` 复制/研究读注册表；梯度由 `ResearchChain` 驱动，
  注册表缺失时回退原硬编码梯度。

### 6.4 缩放 pose 下的 scissor 修复

首轮实现把整个界面放进 `PoseStack` 缩放坐标系后出现编辑框显示异常。根因：`GuiGraphics`
的裁剪矩形（`enableScissor` -> `applyScissor`）**不随 `PoseStack` 变换**，而
`MultiLineEditBox`（经 `AbstractScrollWidget.renderWidget`）内部用 scissor 裁剪编辑内容，
在缩放 pose 下被裁到错误区域。

修复：`PaperMultiLineEditBox` 覆写 `renderWidget(GuiGraphics,int,int,float)`，不再调用会启用 scissor 的
`super.renderWidget`，改为 `pushPose -> translate(0,-scrollAmount) -> renderContents -> popPose ->
renderDecorations` 的绘制流程；纵向超出仍由 `renderContents` 按可视行裁剪。纸面控件保持**透明底框**。
其余控件（`EditBox`、`Button`）不依赖 scissor，不受影响。

> 注：D-notes-6 曾把 `PaperMultiLineEditBox` 基类换为 `AbstractScrollWidget` 自绘；D-notes-7 已改回
> `MultiLineEditBox` 子类，但**保留** `renderWidget` 覆写以继续规避 scissor（本节去 scissor 约定仍然有效）；
> `renderDecorations` 沿用基类实现绘制滚动条。

## 7. 正文投影阴影修复（2026-10-06，D-notes-6）

修复可编辑笔记编辑界面**正文框**文字"加粗"。计划文件
`.opencode/plans/2026-10-06-dreamnote-editor-shadow-fix.md`（audit 后删除）。

### 7.1 根因

vanilla `MultiLineEditBox.renderContents` 与 `EditBox.renderWidget`（1.21.1）用 5 参数
`drawString(Font, String, int, int, int)` 渲染文字，该重载**默认 `dropShadow = true`**
（`GuiGraphics` 5 参重载委托 6 参并传 `true`）。Minecraft 投影阴影为「文字色 ÷ 4」在 `(+1,+1)`
重画（`Font.drawInternal` + `SHADOW_OFFSET`）；正文经 `setColor` tint 成深棕后阴影近黑，深色文字在
浅色羊皮卷上叠出 1px 深色重影 → 视觉"加粗"。阅读屏 `DreamnoteScreen` 走 `drawWordWrap`
（内部传 `false`），无此问题，未改动。

### 7.2 实现

- `client/gui/widget/PaperMultiLineEditBox.java`：改为 `extends AbstractScrollWidget`，自绘正文/光标/选区，
  全部使用 `drawString(..., false)`（无阴影）；透明背景（不调用 `renderBackground`）；不使用 scissor；
  滚动条沿用 `super.renderDecorations()`。
- 新增 `client/gui/widget/PaperTextField.java`：`MultilineTextField` 子类，暴露跨包不可见的
  `protected StringView` 索引（`lineCount`/`lineBegin`/`lineEnd`/`selectionBegin`/`selectionEnd`）。
- `client/gui/widget/PaperEditBox.java`（名称框）：移除 `setBordered(false)` → 整块深色底框；文字改用浅色
  `PaperStyle.NAME_TEXT_COLOR`（深底可读），字号沿用传入字体、与正文一致。
- `client/gui/widget/PaperStyle.java`：新增 `PLACEHOLDER_COLOR`、`CURSOR_COLOR`、`SELECTION_COLOR`、
  `NAME_TEXT_COLOR`，落实"唯一取色源"。
- `client/screen/NoteGuiLayout.java` 仅同步第 47 行注释（`MultiLineEditBox` → `PaperMultiLineEditBox`）；
  `BASE_SCALE` 等数值未改。

> 注：D-notes-7（§8）已弃用上述自绘实现与 `PaperTextField`，正文框基类改回 `MultiLineEditBox`，
> 去阴影/配色改由基于 Accessor Mixin 的自绘 `renderContents` 实现；名称框与 `PaperStyle` 配色源调整仍然有效。

### 7.3 与计划的实现偏差登记

## 8. 正文框输入法（IMBlocker）兼容修复（2026-10-06，D-notes-7）

修复编辑界面**正文框无法输入中文**（名称框正常），并修回由此引入的光标配色与 1px 抖动。
计划文件 `.opencode/plans/2026-10-06-notes-imblocker-input-fix.md`（首版 `@Redirect` 方案）与
`.opencode/plans/2026-10-06-notes-editor-self-draw.md`（改为自绘方案，见 §8.2）（audit 后删除）。

### 8.1 根因

IMBlocker（开发前置 `localRuntime`）仅对原版 `EditBox`（`TextFieldMixin`）与 `MultiLineEditBox`
（`MultiLineEditBoxMixin`）登记「文本输入焦点」；`AbstractWidgetMixin` 的 `focusChanged` 为空实现，
普通 `AbstractWidget`/`AbstractScrollWidget` 子类不会成为焦点候选。屏幕容器
`FocusContainer.MINECRAFT` 默认 `preferredState=false`（锁 IME），未登记的控件不会触发解锁
→ IME 保持关闭，无法输入中文。

D-notes-6 为去投影阴影把正文框改为自绘 `AbstractScrollWidget` 子类，顺带丢失了这一识别
（`PaperEditBox extends EditBox` 不受影响，故名称框仍正常）。

### 8.2 实现

- `client/gui/widget/PaperMultiLineEditBox.java`：基类改回 `MultiLineEditBox`；覆写
  `renderWidget`（`pushPose → translate(0,-scrollAmount) → renderContents → popPose →
  renderDecorations`，不使用 scissor）与 `renderContents` 完全自绘：
  - 正文 `PaperStyle.TEXT_COLOR` + `drawString(..., false)`（去投影）；
  - 光标竖线与文末占位字符用 `PaperStyle.CURSOR_COLOR`；选区用 `PaperStyle.SELECTION_COLOR`；
  - **光标后文本画在正常位置（`cursorLeft + 1`）**，而非原版 `renderContents` 的
    `drawString(before) - 1` 后接续位置，消除光标闪烁时该段文本的 1px 抖动。
  - 输入/焦点/滚动仍继承原版，IMBlocker 的 `MultiLineEditBoxMixin` 恢复生效。
- 新增 `mixin/MultiLineEditBoxAccessor.java`：`@Accessor("textField")` 暴露原版 private 文本状态。
- 新增 `mixin/MultilineTextFieldViewMixin.java` + `client/gui/widget/PDMultilineTextView.java` +
  `mixin/StringViewAccessor.java`：将 `MultilineTextField` 的行/光标/选区索引以 `int` 桥接
  （`StringView` 为 `protected` 嵌套 record，跨包不可引用，经 `@Shadow displayLines` +
  `@Accessor` 读取）。
- `pasterdream.mixins.json`：`client` 数组新增 `MultiLineEditBoxAccessor`、
  `MultilineTextFieldViewMixin`、`StringViewAccessor`。
- 删除 `client/gui/widget/PaperTextField.java`（D-notes-6 遗留，仅旧自绘实现使用）。

### 8.3 与计划的实现偏差登记

- **`PDMultilineTextView` 移出 mixin 包**：初版将其放在 `com.pasterdream.pasterdreammod.mixin`

### 9.4 自动换页仍表现为滚动（追加修复）

首次交付后人工反馈「自动换页仍表现为滚动」。根因：`AbstractScrollWidget.getMaxScrollAmount()`
把滚动量夹在「内容高 − 视口高」，末页不满 18 行时**无法把页首滚到视口顶部**（例：20 行时上限仅
`9*20-162=18px`，而第 2 页页首需 `18*9=162px`），`setViewToChar` 被夹回 → 只滚动不翻页。

修复（`PaperMultiLineEditBox`）：

- 覆写 `getMaxScrollAmount()` 为 `getInnerHeight() - 9`，允许把任意页页首对齐视口顶部（末页不满时其后留白）；
- `setViewToChar` 行判定由 `<=` 改为 `<`，避免落到上一页末行（页首字符与上一行行尾同一下标）；
- 自绘裁剪改为 `lineVisible()`（要求整行完整落在可视区），消除页边界处上一页末行的残余像素；
- `DreamseekerNotesScreen` 初始化改为「初始页 = 光标所在页」（`setValue` 置光标于文末），避免首次按键跳页。

### 9.5 翻页按钮被正文框吞点击（追加修复）

现象：点击 `<` 无法返回上一页。根因**不在分页逻辑**：`ContainerEventHandler.mouseClicked` 按 `children()`
**注册顺序正向**命中并取第一个消费者；而 `MultiLineEditBox.mouseClicked` 会在**整个控件矩形内**
（`withinContentAreaPoint`）吞掉点击。编辑器注册顺序为 `nameBox → bodyBox → prev/next`，`BASE_SCALE = 0.9`
时正文框 `y 47..217` 与按钮 `y 207..225` **重叠 10px**：按钮中心（≈216）落在正文框内 → 点击被正文框抢先
消费并 `seekCursorScreen` 挪动光标，按钮永远收不到；光标一变，`beforeRender` 又把视图同步回光标所在页，
表现为「点了没反应」。

修复（按用户决策「背景+内容上移、按钮不动」）：

- `NoteGuiLayout` 新增 `CONTENT_SHIFT = 12`：标题/正文/名称框/页码锚点整体上移 12px，**按钮锚点不参与上移**，
  按钮因而相对正文框下移；正文框 `35..205`、按钮 `207..225`，重叠消除并留 2px 间隙。
- `AbstractPaperScreen.drawPaper` 底图同步上移 `CONTENT_SHIFT`，保持文字与纹理锚点对齐。
- 编辑屏保存失败提示改画在页码位（居中、非空时替代页码），避免与正文/按钮叠压。
