# 寻梦者笔记系统重做

- 状态：已实现（P0–P3 + P4；已过 audit/guards 并修复其发现项）
- 分支：`dev/milestore/momonyako-alpha`
- 计划文件：`.opencode/plans/寻梦者笔记重做.md`（audit 后删除）
- 关联：`docs/架构/主模组架构详解.md`、`docs/参考/API边界.md`、`docs/架构/模块边界.md`

## 1. 背景

原 `dreamnotes_0..14` 为固定叙事页，正文烘焙在 `textures/screens/dreamnotes_guiN(_en).png`，
经 `dreamnotes_gui_0` 容器菜单展示。本重做改为**数据驱动正文 + Markdown 渲染 + 18 行/120px 自动分页**，
并新增**玩家可编辑双语笔记**，同时把研究台梯度改为数据驱动。

## 2. 架构

### 2.1 数据模型（同步动态注册表）

- `pasterdream:dreamnotes`：`NoteDefinition`（title/body 语言映射、unlock、required、
  locate_shadow_base、give、extra_messages）。目录 `data/<ns>/pasterdream/dreamnotes/<entry>.json`。
- `pasterdream:note_research`：`ResearchChain`（steps、completion、completion_exp）。
  目录 `data/<ns>/pasterdream/note_research/<entry>.json`。
- 均经 `DataPackRegistryEvent.NewRegistry` 注册并提供同步 codec，datapack 定义自动同步客户端。
- 注册与查询：`dreamnotes/PDNoteRegistry`、`dreamnotes/NoteDefinition`、`dreamnotes/ResearchChain`。

### 2.2 通用类（上收 PasterDreamAPI）

- `api/text/NoteText`：Markdown 子集（`*` 斜体 / `--` 删除线 / `__` 下划线 / `<name>`·`<#RRGGBB>` 颜色 /
  `\` 转义 / `§` 透传）转 `Component`（common）。
- `api/text/NoteLimits`：折行宽 120、每页 18 行、最多 128 页、正文 28000 字节（双端共用）。
- `api/client/text/NotePagination`：`@OnlyIn(CLIENT)` 的 `StringSplitter` 折行分页。

### 2.3 交互与网络

- 废弃 `dreamnotes_gui_0` 菜单，改 `OpenNotePayload`(S2C) + `SaveNotePayload`(C2S)。
- 客户端桥 `client/PDClientNoteScreens`（`PDNetwork` 经反射转发，避免 common 引用客户端）。
- 界面：`client/screen/DreamnoteScreen`（只读分页渲染）、`client/screen/DreamseekerNotesScreen`（编辑）。
  共用羊皮卷底图 `textures/screens/dreamnote_paper.png`，**无工具栏**。

### 2.4 物品与获取

- `dreamnotes_0..14` 保留注册名，统一 `item/DreamnotesItem`（数据驱动，右键下发打开包）。
- 新增可编辑物品 `dreamseeker_notes`（`item/DreamseekerNotesItem`，`CUSTOM_DATA` 双语字段），
  可合成（纸 + 墨囊）。
- 研究台 `block/entity/ResearchTableBlockEntity` 复制/研究读注册表；梯度由 `ResearchChain` 驱动，
  注册表缺失时回退原硬编码梯度。

## 6. GUI 排版修复（2026-10-05，D-notes-5）

修复三类界面缺陷：编辑框深色黑框、书写位置错误（标题落在卷轴卷起区）、底图尺寸写死

### 6.1 实现结构

- `client/screen/NoteGuiLayout.java`：`TEX_W/TEX_H=775/1024`、`BASE_W=200`、
  `BASE_SCALE`（唯一可调旋钮）、纹理锚点；`compute(screenW, screenH)` 返回逻辑坐标 `Frame`。
- `client/screen/AbstractPaperScreen.java`：持有共享底图常量与 `Frame`，统一
  `translate + scale` 渲染骨架与输入坐标反变换；`drawPaper` 由基类具体实现，

- `client/gui/widget/PaperEditBox.java`、`PaperMultiLineEditBox.java`、`PaperStyle.java`：
  纸面风格控件；早期实现为 `MultiLineEditBox` 子类 + `GuiGraphics.setColor` tint（见 D-notes-5）。
  **2026-10-06 起正文框改为自绘控件**（D-notes-6，见 §7）。
- 修改 `DreamnoteScreen`、`DreamseekerNotesScreen` 继承基类，删除本地尺寸常量。

### 6.2 与计划的实现偏差登记

### 6.4 缩放 pose 下的 scissor 修复

首轮实现把整个界面放进 `PoseStack` 缩放坐标系后出现编辑框显示异常。根因：`GuiGraphics`
的裁剪矩形（`enableScissor` -> `applyScissor`）**不随 `PoseStack` 变换**，而
`MultiLineEditBox`（经 `AbstractScrollWidget.renderWidget`）内部用 scissor 裁剪编辑内容，
在缩放 pose 下被裁到错误区域。

修复：`PaperMultiLineEditBox` 覆写 `renderWidget(GuiGraphics,int,int,float)`，不再调用会启用 scissor 的
`super.renderWidget`，改为 `pushPose -> translate(0,-scrollAmount) -> renderContents -> popPose ->
renderDecorations` 的绘制流程；纵向超出仍由 `renderContents` 按可视行裁剪。纸面控件保持**透明底框**。
其余控件（`EditBox`、`Button`）不依赖 scissor，不受影响。

> 注：D-notes-6 后 `PaperMultiLineEditBox` 基类由 `MultiLineEditBox` 换为 `AbstractScrollWidget`，
> 上述自绘/去 scissor 约定保持一致；`renderDecorations` 沿用基类实现绘制滚动条。

## 7. 正文投影阴影修复（2026-10-06，D-notes-6）

修复可编辑笔记编辑界面**正文框**文字"加粗"。计划文件
`.opencode/plans/2026-10-06-dreamnote-editor-shadow-fix.md`（audit 后删除）。

### 7.1 根因

vanilla `MultiLineEditBox.renderContents` 与 `EditBox.renderWidget`（1.21.1）用 5 参数
`drawString(Font, String, int, int, int)` 渲染文字，该重载**默认 `dropShadow = true`**
（`GuiGraphics` 5 参重载委托 6 参并传 `true`）。Minecraft 投影阴影为「文字色 ÷ 4」在 `(+1,+1)`
重画（`Font.drawInternal` + `SHADOW_OFFSET`）；正文经 `setColor` tint 成深棕后阴影近黑，深色文字在
浅色羊皮卷上叠出 1px 深色重影 → 视觉"加粗"。阅读屏 `DreamnoteScreen` 走 `drawWordWrap`
（内部传 `false`），无此问题，未改动。

### 7.2 实现

- `client/gui/widget/PaperMultiLineEditBox.java`：改为 `extends AbstractScrollWidget`，自绘正文/光标/选区，
  全部使用 `drawString(..., false)`（无阴影）；透明背景（不调用 `renderBackground`）；不使用 scissor；
  滚动条沿用 `super.renderDecorations()`。
- 新增 `client/gui/widget/PaperTextField.java`：`MultilineTextField` 子类，暴露跨包不可见的
  `protected StringView` 索引（`lineCount`/`lineBegin`/`lineEnd`/`selectionBegin`/`selectionEnd`）。
- `client/gui/widget/PaperEditBox.java`（名称框）：移除 `setBordered(false)` → 整块深色底框；文字改用浅色
  `PaperStyle.NAME_TEXT_COLOR`（深底可读），字号沿用传入字体、与正文一致。
- `client/gui/widget/PaperStyle.java`：新增 `PLACEHOLDER_COLOR`、`CURSOR_COLOR`、`SELECTION_COLOR`、
  `NAME_TEXT_COLOR`，落实"唯一取色源"。
- `client/screen/NoteGuiLayout.java` 仅同步第 47 行注释（`MultiLineEditBox` → `PaperMultiLineEditBox`）；
  `BASE_SCALE` 等数值未改。

### 7.3 与计划的实现偏差登记

- `PaperTextField` 行索引由计划草案的 `List<int[]> wrappedLines()` 改为**无分配的索引访问器**
  `lineCount()` / `lineBegin(int)` / `lineEnd(int)`（等价且避免每帧分配）；`selectionBegin/End()` 不变。
- 子类访问 `protected StringView` 编译通过（`:PasterDream:compileJava`、全量 `compileJava` 均成功），
  未启用计划的 `Font.getSplitter()` 备选方案。
