# 寻梦者笔记系统重做

- 状态：已实现（P0–P3 + P4；已过 audit/guards 并修复其发现项）
- 分支：`dev/milestore/momonyako-alpha`
- 计划文件：`.opencode/plans/寻梦者笔记重做.md`（audit 后删除）
- 关联：`docs/架构/主模组架构详解.md`、`docs/参考/API边界.md`、`docs/架构/模块边界.md`

## 1. 背景

原 `dreamnotes_0..14` 为固定叙事页，正文烘焙在 `textures/screens/dreamnotes_guiN(_en).png`，
经 `dreamnotes_gui_0` 容器菜单展示。本重做改为**数据驱动正文 + Markdown 渲染 + 18 行/120px 自动分页**，
并新增**玩家可编辑双语笔记**，同时把研究台梯度改为数据驱动。

## 2. 架构

### 2.1 数据模型（同步动态注册表）

- `pasterdream:dreamnotes`：`NoteDefinition`（title/body 语言映射、unlock、required、
  locate_shadow_base、give、extra_messages）。目录 `data/<ns>/pasterdream/dreamnotes/<entry>.json`。
- `pasterdream:note_research`：`ResearchChain`（steps、completion、completion_exp）。
  目录 `data/<ns>/pasterdream/note_research/<entry>.json`。
- 均经 `DataPackRegistryEvent.NewRegistry` 注册并提供同步 codec，datapack 定义自动同步客户端。
- 注册与查询：`dreamnotes/PDNoteRegistry`、`dreamnotes/NoteDefinition`、`dreamnotes/ResearchChain`。

### 2.2 通用类（上收 PasterDreamAPI）

- `api/text/NoteText`：Markdown 子集（`*` 斜体 / `--` 删除线 / `__` 下划线 / `<name>`·`<#RRGGBB>` 颜色 /
  `\` 转义 / `§` 透传）转 `Component`（common）。
- `api/text/NoteLimits`：折行宽 120、每页 18 行、最多 128 页、正文 28000 字节（双端共用）。
- `api/client/text/NotePagination`：`@OnlyIn(CLIENT)` 的 `StringSplitter` 折行分页。

### 2.3 交互与网络

- 废弃 `dreamnotes_gui_0` 菜单，改 `OpenNotePayload`(S2C) + `SaveNotePayload`(C2S)。
- 客户端桥 `client/PDClientNoteScreens`（`PDNetwork` 经反射转发，避免 common 引用客户端）。
- 界面：`client/screen/DreamnoteScreen`（只读分页渲染）、`client/screen/DreamseekerNotesScreen`（编辑）。
  共用羊皮卷底图 `textures/screens/dreamnote_paper.png`，**无工具栏**。

### 2.4 物品与获取

- `dreamnotes_0..14` 保留注册名，统一 `item/DreamnotesItem`（数据驱动，右键下发打开包）。
- 新增可编辑物品 `dreamseeker_notes`（`item/DreamseekerNotesItem`，`CUSTOM_DATA` 双语字段），
  可合成（纸 + 墨囊）。
- 研究台 `block/entity/ResearchTableBlockEntity` 复制/研究读注册表；梯度由 `ResearchChain` 驱动，
  注册表缺失时回退原硬编码梯度。

### 6.1 实现结构

- `client/screen/NoteGuiLayout.java`：`TEX_W/TEX_H=775/1024`、`BASE_W=200`、

  子类仅实现 `renderContent` 与 `initWidgets`。
- `client/gui/widget/PaperEditBox.java`、`PaperMultiLineEditBox.java`、`PaperStyle.java`：
  纸面风格控件（隐藏 vanilla 底框、深棕文字）；多行框因父类文字色硬编码且 `textField` 私有，
  以 `GuiGraphics.setColor` tint 换算实现。
- 修改 `DreamnoteScreen`、`DreamseekerNotesScreen` 继承基类，删除本地尺寸常量。

### 6.2 与计划的实现偏差登记

- `Frame` 的底图字段由计划草案的 `paperW/paperH` 定为 `designW/designH`（在缩放 pose 内

  `ClientHooks.drawScreen` 包裹 `renderWithTooltip` 触发，与本屏是否调用 `super.render` 无关。

### 6.4 缩放 pose 下的 scissor 修复

首轮实现把整个界面放进 `PoseStack` 缩放坐标系后出现编辑框显示异常。根因：`GuiGraphics`
的裁剪矩形（`enableScissor` -> `applyScissor`）**不随 `PoseStack` 变换**，而
`MultiLineEditBox`（经 `AbstractScrollWidget.renderWidget`）内部用 scissor 裁剪编辑内容，
在缩放 pose 下被裁到错误区域。

修复：`PaperMultiLineEditBox` 覆写 `renderWidget(GuiGraphics,int,int,float)`，不再调用
`super.renderWidget`（也就不启用 scissor），改为自身 `renderBackground`（透明）+
`renderContents` + `renderDecorations` 的绘制流程；纵向超出仍由 `renderContents` 按可视行裁剪。
纸面控件保持**透明底框**。其余控件（`EditBox`、`Button`）不依赖 scissor，不受影响。
