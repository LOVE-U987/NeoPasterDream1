# 设计方向

> 本文档记录当前设计方向与已定设计决策。
> 本项目采用测试驱动开发：设计决策的验收标准是编译 + VERIFY 套件 + 游戏实测（见[测试指南](../开发指南/测试指南.md)），本文档是现状与决策的速览，与代码/测试不一致时以代码为准。

## 2. 架构设计方向

| 方向 | 现状 |
|------|------|
| 多模块 + thin 发行 | 附属不内嵌 API，运行时由主模打包提供；API 可独立发布（`maven-publish` 已配置） |
| Facade + Builder + Result | 所有注册系统统一三件套模式，DeferredRegister 由 API 前置统一挂总线 |
| VFX 特效系统 | 七子系统（氛围/过场/幽灵/冲击帧/粒子发射器/屏幕/震动）三层结构：公共定义在 API `effect`，客户端执行在 API `client/effect`，跨端走 Payload |
| 玩法接口域 | San / 融梦能量通过 API 配置接口解耦：附属实现 `ISanSystemConfig` / `IMeltDreamEnergySystemConfig`，主模消费只依赖接口 |

## 3. 内容设计方向

当前内容版图（截至 2026-09-15）：

- 四维度：染梦（自定义 ChunkGenerator/BiomeSource）、灯影、风之旅途、亚伦柯斯竞技场，加主世界裂隙入口
- 主流程闭环：染梦 → 暮影 → 无名全对话 → 影之抉择（环境二选一）→ 竞技场 → 风之旅途，VERIFY `main-flow` 覆盖
- 工艺体系：武器工坊（铁砧/锻炉/冷却/磨盘）、暗影高炉、梦境炼药锅、研究台/蓝图
- 玩法系统：San 理智、融梦能量、瞬身术/斗篷、卡勒卡牌、梦笔记、纪念物、饰品

## 5. 已定设计决策（Neo 增强 / 有意不做）

以下决策已定稿，**不是缺口，勿当作待办**（详见[开发进度](开发进度.md) 5.3）：

| 决策 | 内容 | 类型 |
|------|------|------|
| 迷梦进维 Y clamp | 进风维落点 `clamp(srcY, min, maxBuild-2)`，防原版裸传顶天；XY 与包序列仍对齐原版 | Neo 增强 |
| 暮影 ANIMATION 仅 idle | 动画 JSON 只含 idle `"0"`，原版从不驱动 oneshot，不为"补动画"开任务 | 有意不驱动 |
| HUD cloudmist 客户端本地重算 | 客户端按 Y 本地计算（公式与服务端一致），不同步 NBT 不影响 HUD | 设计分叉 |
| 进灯影赠骨针默认 true | 对齐图鉴叙事，配置可关 | 产品决策 |
| 暮影 number 清零 | 事件结束与再点燃均清零，可重复守卫战节点 | Neo 增强 |
| 风旅祭坛合并 | 五方块 `wind_knight_spawnblock_0..4` 合并为单方块 + `STAGE` 属性 + `FACING` | Neo 增强 |
| 祭坛阶段贴图共用单图 | 原版五阶段共用一张贴图，阶段观感靠 geo mesh 不靠换图 | 还原 |
| 破风幕结构 ID 修正 | `breakwing` → `breakwind_curtain_0`，修正原版 MCreator 拼写，旧 id 不再注册 | 有意修正 |
| VERIFY 超平 locate SKIP | twilight/wind 专项不把自然 locate 当 fail，自然档手测另行记录 | 套件设计 |
