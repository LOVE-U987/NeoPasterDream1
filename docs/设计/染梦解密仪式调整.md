# 染梦解密仪式调整：书桌保留、上半格触发与采集

> 状态：已实现
> 日期：2026-10-17
> 适用范围：`PasterDream` 主模块

## 1. 背景

染梦世界有两处书桌解密仪式：

- 花园解密：`flower_11`（冶梦莲）→ `flower_12`（迷梦冶梦莲）
- 雪傀儡解密：`flower_16` → `flower_17`（冻结之花）

原模组在仪式成功后销毁 `dyedream_desk`（染梦书桌）。当前项目没有书桌合成配方，书桌只能从结构中获取，导致每次解密都消耗一个不可回收的书桌。同时，玩家反馈以下两个问题：

1. 花园解密只有点击 `flower_11` 下半格才能触发，点击上半格无反应。
2. 剪刀/园艺钳破坏 `flower_11`、`flower_12` 的上半格没有物品掉落。

## 2. 调整内容

### 2.1 仪式不再销毁书桌

- 花园解密删除成功后 `destroyBlock(pos.below(3), false)`。
- 雪傀儡解密删除成功后 `destroyBlock(pos.below(3), false)`。
- 书桌仍作为触发条件参与校验，只是不再被消耗；书桌内 NBT 与成书内容保持不变。

这是相对原模组的**有意差异**。

### 2.2 花园解密支持点击上半格

`DyedreamGardenDecryptFlowerBlock.tryDecrypt` 在维度校验前将上半格点击坐标归一化到下半格，再执行书桌与花阵校验。点击上下半格的行为完全一致。

这是相对原模组的**缺陷修复**。

### 2.3 双层植物上半格可采集

`DyedreamDoublePlantBlock` 新增 `playerWillDestroy` 覆写：生存模式下破坏上半格时，若下方为同一方块的下半格，使用下半格状态与玩家主手工具补一次掉落。

- 剪刀/园艺钳破坏上下半格均掉落 1 个本体。
- 空手或其他工具仍不掉落。
- 创造模式仍不掉落。
- 下半格原有掉落路径不变，不会双倍掉落。

该修复覆盖全部染梦双层植物（`flower_7/10/11/12/18`、双层草等）。这是相对原模组的**体验修复**，不改变剪刀/园艺钳限定掉落的设计。

## 3. 验收

`dyedream` VERIFY 套件新增/更新以下断言：

| 断言 | 内容 |
|------|------|
| `dyedream.garden.success` | 下半格触发成功，花 12 上下成对，书桌保留 |
| `dyedream.garden.success_from_upper` | 上半格触发成功，花 12 上下成对，书桌保留 |
| `dyedream.garden.fail_wrong_layout` | 花阵错误时不触发，书桌保留 |
| `dyedream.snowpuzzle.success` | 雪傀儡解密成功，花 17 生成，书桌保留 |
| `dyedream.snowpuzzle.fail_no_mobs` | 缺少生物时不触发，书桌保留 |
| `dyedream.flower11.drops` | 剪刀/园艺钳破坏上下半格均掉落 1 |
| `dyedream.flower11.no_drop_empty` | 空手破坏上下半格均不掉落 |
| `dyedream.flower12.drops` | 剪刀/园艺钳破坏上下半格均掉落 1 |
| `dyedream.flower12.no_drop_empty` | 空手破坏上下半格均不掉落 |

## 4. 非目标

- 不添加染梦书桌合成配方。
- 不修改书桌战利品表。
- 不改变 `flower_12` 的剪刀/园艺钳限定掉落设计。
