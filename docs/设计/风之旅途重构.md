# 风之旅途维度重构设计

> 原始创意文案：[`风之旅途重构设计文案.md`](风之旅途重构设计文案.md)（含《评审确认记录》）
> 关联先例实现：`worldgen/chunkgen/DyedreamChunkGenerator.java`、`worldgen/chunkgen/DyedreamBiomeSource.java`、`worldgen/feature/FloatingIslandFeature.java`、`api/client/sky/SkyboxAPI.java`、`api/worldgen/decor/`
> 关联注册点：`registry/PDWorldgenRegistries.java`（`CHUNK_GENERATORS` / `BIOME_SOURCES`）、`registry/PDFeatures.java`、`registry/PDBiomes.java`、`world/WindJourneyEvents.java`
> 关联现状配置：`data/pasterdream/dimension/wind_journey_world.json`、`data/pasterdream/dimension_type/wind_journey_world.json`、`data/pasterdream/worldgen/noise_settings/wind_journey_world.json`、`data/pasterdream/worldgen/biome/wind_journey_*.json`
> 记录日期：2026-09-26　状态：已评审定稿，待实施（分期见 §8）

## 1. 背景与目标

风之旅途现由 `minecraft:end_islands` 噪声生成松散的浮岛（噪声地形带 Y 0~128，维度范围 0~255），无法支撑"中心主导岛 + 环绕环岛 + 岛下云托"的集群形貌，也无法按岛体几何分配群系（如"蛀空岛内部生态圈"要求群系范围由结构尺寸决定）。

重构目标：改为**岛系集群**地形范式——每簇岛系由确定性布局决定主岛形状、环岛、蛀空区、云托与风向，并由同一布局驱动群系分配与植被装饰。

创意来源：《天境》《天空之城》。

## 2. 设计内容

### 2.1 岛体结构

| 结构 | 规格 |
|------|------|
| 风之主岛 | 半径 25~50 格；边缘凹凸不平，总体呈不规则圆形；下体随机漏斗状；地表起伏 2~5 格 |
| 风之岛云托 | 与主岛尺寸匹配的长状实心云团，卡通云外形；**禁止**云朵直接平贴岛底，须由中大型云团构成、侧边云团拉伸方向贴合，形成"托举飞行于空中"的观感 |
| 风之岛之环 | 环绕主岛的破碎化环状结构，与主岛间距 10~15 格，灵感取自木星环 |
| 垂直结构 | 岛体依 Y 形成多层结构；中大型树下方出现长条状贴合岛体的风柏树叶 |

### 2.2 植被分层

- **大型植被**生于中心主岛；**小型植被**生于四周环形破碎岛
- **垂吊植被**随机生于中大型树的枝节、树干与岛体岩石下方，丰富植被与垂直层次
- **蛀空生态圈**：部分中型岛内部被植物蛀空，内部形成由苔藓 + 小型植被 + 垂吊植被构成的生态圈；蛀空岛的地表植被更丰盛，岛体出现因蛀空形成的小洞，岛下出现大量长条状贴合岛体的风柏树叶

### 2.3 群系

| 群系 | 定位 | 要点 |
|------|------|------|
| 热气球群系 | 主要群系 | 现状保留，无需修改 |
| 风之岛群系（新增） | 密集小岛 | 点噪波纹理生成大量风之岛；主岛与环岛之间设限制距离，避免连成大片地面地形；少量热气球悬空 |
| 风柏森林（新增） | 主岛地面 | 需大片平坦地面才生成；垂直结构与垂吊植被丰富；树林自岛体中心向外扩开，并对岛体边缘保持距离 |
| 风柏生态圈（新增） | 蛀空岛内部 | 真群系（独立雾色/草色，F3 可见）；范围由蛀空结构尺寸决定 |
| 风蚀群柏岛（新增） | 风蚀集群 | 天气恒为暴雨（含雷暴），风力更强；每簇风向唯一且与邻近群系一致；地面几乎没有植被，若有树木则主干粗壮、枝叶定向倾斜与拉伸；向风面圆滑、背风面凹凸不平并带吹落方块形成的拖尾，环岛已丢失 |

### 2.4 天空

以天体类 API 为各群系制作独一无二的天体、极光、光带。

### 2.5 风柏河

- 水深 1~2 格、宽 4~6 格；主动贴合地形上下起伏
- 使用雕刻算法模拟现实河流形态；多发源于风柏森林，由森林内向岛体边缘发育
- 地形高度落差大于 2 格视为不可越过，即河流终点
- 紧邻河流的方块替换为风柏沙；流向岛外的部分形成岛缘瀑布

## 3. 评审确认决策（2026-09-26）

| 编号 | 决策 | 技术落点 |
|------|------|---------|
| 1 | 文案勘误："垂钓植被"为垂吊植被、"导体"为岛体、"风蚀群泊岛"统一为风蚀群柏岛 | 文案修订完成 |
| 2 | 风柏生态圈为**真群系**（独立雾色/草色，F3 可见） | 自定义 `BiomeSource` |
| 3 | 风蚀群柏岛暴雨**包含雷暴** | 群系常驻降雨 + 程序化闪电 + 雷声氛围 |
| 4 | 旧存档地形接缝走提示 + 备份流程 | 复用 PDSaveCompat 体系 |
| 5 | 区域固定风向为**独立分支**，与现有"日更全局风向"并存 | 风蚀群系优先取区域风向，其余沿用日更 |
| 6 | 维度纵向扩展：底部下探约 50~100 格，Y 上限相应抬高 | dimension_type 与地形带配置（§4.8） |
| 7 | 热气球结构锚定逻辑无需修改 | 保持现状 |

## 4. 技术架构

### 4.1 核心：IslandLayoutManager（确定性布局）

`种子 + 集群网格坐标 → 布局包`：主岛形状与半径、环岛位置、云托锚点与拉伸方向、蛀空区、风向、岛屿原型（普通 / 风蚀）。

**三方共用**：地形生成器、`BiomeSource`、装饰 Feature 统一查询，禁止各自另算一套（否则群系与地形会错位）。

按三零判定（零 `PD*` 注册表 / 零玩法数值 / 零具体资产路径）通过，规格参数由主模注入 → 上收 `PasterDreamAPI` 的 `api/worldgen/`。

### 4.2 地形：WindJourneyChunkGenerator（主模）

- 继承 `NoiseBasedChunkGenerator`，重写 `fillFromNoise`：先调用 `super.fillFromNoise()` 完成 NoiseChunk 创建与 blend 初始化，再覆盖为岛系地形（`doFill` 在 NeoForge 21.1.219 为 `private` 无法直接重写——染梦先例已踩此坑）
- 岛体高度场由 IslandLayoutManager 逐列求值：**任何区块可独立算出自己所属岛系的切片**，从根上规避 Feature 的 ±1 区块写半径限制（`FloatingIslandFeature` 注释记录的 "Detected setBlock in a far chunk" 刷屏与光照 DataLayer NPE）
- 云托、漏斗状下体、蛀空、风蚀形变、风柏河雕刻均在本层完成
- 注册：`PDWorldgenRegistries.CHUNK_GENERATORS`（`Registries.CHUNK_GENERATOR`）

### 4.3 群系：WindJourneyBiomeSource（主模）

- 自定义 `BiomeSource`（替代现 `multi_noise`），携带 CODEC（参照 `DyedreamBiomeSource`）
- 按位置向 IslandLayoutManager 查询几何 → 按 §6 判定群系
- 注册：`PDWorldgenRegistries.BIOME_SOURCES`（`Registries.BIOME_SOURCE`）

### 4.4 装饰 Feature（主模）

- 风之树：大/中/小 × 低/中/高 × 多枝节/少枝节
- 风柏附生植被：由苔藓、小型植被（如风柏草）、垂吊植被构成，生成时主动契合地形（地面偏小型植被与苔藓，浮空位置偏垂吊植被）
- 风柏森林：平坦地面判定 + 自岛体中心向外扩开 + 对岛缘保持距离（几何取自布局）
- 沿用 `PDFeatures` 注册与 `api/worldgen/decor`（`DecorationBuilder` / `TreePlacerAPI` / `GenericDecorationFeature` / `RegionClaimManager`）

### 4.5 天空内容

`SkyboxAPI.register(content, SkyCondition.biome(...))` 按群系激活。现成内容类：`AuroraSkyContent`（极光）、`SkyRibbonContent`（光带）、`TexturedPlanetSystemSkyContent`（天体）、`StarFieldSkyContent` / `StarClusters`、`ShootingStarSkyContent`、`ConstellationSkyContent`、`RainbowSkyContent`、`SkyTintContent`；亦可走数据驱动 `data/pasterdream/skyboxes/*.json`（`SkyboxPresetLoader`）。

风蚀群柏岛以 `SkyTintContent` 压暗天空。

### 4.6 雷暴（风蚀群柏岛）

- **常驻降雨**：群系 JSON `has_precipitation: true` + `downfall: 1.0`
- **雷暴**：`WindJourneyEvents` 服务端 tick 检测玩家位于风蚀群系 → 定时程序化闪电 + 雷声
- **约束**：非主世界维度使用 `DerivedLevelData`，天气镜像主世界，不可也不应独立设置全局雷暴；程序化闪电可达到"常驻雷暴"观感且不外泄到其他维度

### 4.7 风向分支

现有 `WindJourneyEvents` 的"日更全局风向"（0~7，含广播、顺风判定、羽毛粒子）**保持不动**。新增统一查询入口：位置处于风蚀集群 → 返回该集群固定风向（低频噪声按集群中心采样，相邻集群自然一致）；否则返回日更方向。顺风判定、树木倾斜与拖尾生成统一走此入口。

### 4.8 纵向扩容（数值拟定，待确认）

| 项 | 现状 | 拟定 |
|----|------|------|
| dimension_type | `min_y: 0 / height: 256`（范围 0~255） | `min_y: -64 / height: 320`（范围 **-64~255**） |
| 噪声/地形带 | `min_y: 0 / height: 128` | 同步扩展，容纳云托下探与垂吊叶条 |
| logical_height | 256 | 同步调整 |

即顶部维持 255 不变、底部新增 64 格（落在"MOLU 给定 50~100 格"区间内），Y 上限的可用地形空间由 128 抬至 255。

## 5. 模块归属

| 内容 | 模块 | 依据 |
|------|------|------|
| IslandLayoutManager 及确定性布局/几何工具 | `PasterDreamAPI` `api/worldgen/` | 三零判定通过，参数由主模注入 |
| WindJourneyChunkGenerator / WindJourneyBiomeSource | `PasterDream` | 含 PD 群系与方块的具体维度生成 |

| 雷暴与风向逻辑 | `PasterDream`（`WindJourneyEvents` 分支） | 事件处理器不上收 API |

详见 [`../参考/API边界.md`](../参考/API边界.md)。

## 6. 群系判定表（BiomeSource 规则草案）

| 条件 | 群系 |
|------|------|
| 位于风蚀原型集群 | 风蚀群柏岛 |
| 位于蛀空区（岛体内部） | 风柏生态圈 |
| 位于主岛平坦表面区（森林区，且离岛缘 > 阈值） | 风柏森林 |
| 位于小型岛 / 环岛 | 风之岛群系 |
| 其余（空域、主岛非林区） | 热气球群系 |

阈值与形态参数由主模规格注入，布局判定与生成器共用同一 `IslandLayoutManager`。

## 7. 数据与资源配置清单

- **群系**：新增 4 个（风之岛 / 风柏森林 / 风柏生态圈 / 风蚀群柏岛），`PDBiomes` 补 `ResourceKey` 常量
- **地形**：`WindJourneyChunkGenerator` + `WindJourneyBiomeSource` 注册；维度 JSON 切换 `generator.type` 与 `biome_source.type`
- **特征**：configured / placed feature + `neoforge/biome_modifier/*.json`（对齐现有 `wind_journey_vegetation` / `wind_journey_ground_vegetal` 等）
- **天空**：`data/pasterdream/skyboxes/*.json` 按群系配置
- **方块**：复用现有风柏系列方块，缺失项（如风柏沙）补注册
- **存档**：PDSaveCompat 检测 / 备份 / 提示（见 [`存档兼容层.md`](存档兼容层.md)）

## 9. 风险与约束

| 风险 | 说明 | 对策 |
|------|------|------|
| 跨区块地形写入半径 | Feature 仅可写 ±1 区块 | 地形全部走 ChunkGenerator，Feature 只做点状装饰 |
| 岛缘瀑布水物理 | 岛外流水持续更新与扩散 | 限制水源与流向，必要时专用流体/水位上限，实测性能 |
| 生成性能 | 逐列几何求值 + 多类 Feature | 布局结果按区块缓存，几何求值保持轻量 |
| 旧存档接缝 | 地形重做后与旧区块不衔接 | PDSaveCompat 提示 + 备份 |
| 群系与地形错位 | 两套判定各算一套 | 生成器与 BiomeSource 强制共用 IslandLayoutManager |

## 10. 有意差异与说明

- **相对原版**：风之旅途由纯噪声浮岛改为岛系集群，属有意增强；热气球等既有结构的锚定逻辑不动。
- **相对现状**：地形、群系、天空全面重构；旧 ID 处理遵循 [`ID迁移计划.md`](ID迁移计划.md)。
- 勘误记录见 §3 第 1 条。

## 11. 待确认项

1. **纵向扩容数值**：拟 `min_y: -64 / height: 320`（顶部 255 不变、底部 +64），待最终确认。
2. **现有群系 `wind_journey_desert`（风之旅途沙漠）去留**：重构群系表（§2.3）中未包含沙漠群系，需明确保留（作为某类岛）还是按 ID 迁移惯例废弃。
3. **"主岛与环岛的限制距离"具体数值**：设计仅描述为"限制距离"，需定值。
