# 添加物品

> 本教程将指导你从零开始添加一个自定义物品。

---

## 概述

我们将添加一个名为 `dream_shard` 的物品,具有以下特性:
- 基础物品,无特殊逻辑
- 可堆叠到 64
- 有对应的创造标签

---

## 步骤 1: 创建物品类

### 1.1 创建物品类文件

创建文件 `PasterDream/src/main/java/com/pasterdream/pasterdreammod/item/DreamShardItem.java`:

```java
package com.pasterdream.pasterdreammod.item;

import net.minecraft.world.item.Item;

/**
 * 梦境碎片物品
 * 
 * 一种稀有的材料,用于合成高级物品。
 */
public class DreamShardItem extends Item {
    public DreamShardItem(Properties properties) {
        super(properties);
    }
}
```

### 1.2 如果需要特殊逻辑

如果物品需要特殊逻辑 (如右键使用),可以覆写相应方法:

```java
@Override
public InteractionResultHolder<ItemStack> use(Level level, Player player, InteractionHand hand) {
    ItemStack stack = player.getItemInHand(hand);
    
    // 右键使用逻辑
    if (!level.isClientSide) {
        // 执行逻辑
        return InteractionResultHolder.sidedSuccess(stack, level.isClientSide);
    }
    
    return InteractionResultHolder.pass(stack);
}
```

---

## 步骤 2: 注册物品

### 2.1 在 PDItems.java 中注册

打开 `PasterDream/src/main/java/com/pasterdream/pasterdreammod/registry/PDItems.java`,添加注册:

```java
// 在 PDItems 类中添加
public static final DeferredItem<Item> DREAM_SHARD = 
    PDItems.ITEMS.register("dream_shard", () -> new DreamShardItem(
        new Item.Properties()
            .stacksTo(64)));
```

### 2.2 注册到创造标签

在同一文件中,注册到创造标签:

```java
// 在 PDCreativeTabs.java 中添加
Items.DREAM_SHARD,  // 在合适的标签中添加
```

---

## 步骤 3: 创建资源文件

### 3.1 物品模型

创建文件 `PasterDream/src/main/resources/assets/pasterdream/models/item/dream_shard.json`:

```json
{
    "parent": "item/generated",
    "textures": {
        "layer0": "pasterdream:item/dream_shard"
    }
}
```

### 3.2 纹理

创建纹理文件 `PasterDream/src/main/resources/assets/pasterdream/textures/item/dream_shard.png`。

**注意**: 纹理需要是 16x16 像素的 PNG 文件。

---

## 步骤 4: 添加语言文件

### 4.1 英文

在 `PasterDream/src/main/resources/assets/pasterdream/lang/en_us.json` 中添加:

```json
{
    "item.pasterdream.dream_shard": "Dream Shard"
}
```

### 4.2 中文

在 `PasterDream/src/main/resources/assets/pasterdream/lang/zh_cn.json` 中添加:

```json
{
    "item.pasterdream.dream_shard": "梦境碎片"
}
```

---

## 步骤 5: 测试

### 5.1 编译测试

```bash
.\gradlew compileJava
```

### 5.2 运行客户端

```bash
.\gradlew runClient
```

### 5.3 验证功能

1. 进入创造模式
2. 在创造标签中找到物品
3. 检查物品名称是否正确显示
4. 检查物品纹理是否正确

## 扩展: 添加食物物品

如果需要添加食物物品,请参考:

```java
// 使用 FoodItemBuilder
ItemResult<Item> result = ItemAPI.createFood("my_food")
    .properties(new Item.Properties()
        .stacksTo(64)
        .nutrition(3)
        .saturationModifier(0.8f))
    .effect(() -> new MobEffectInstance(MobEffects.REGENERATION, 200, 0), 1.0f)
    .build();
```
