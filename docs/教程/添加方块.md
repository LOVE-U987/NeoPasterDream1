# 添加方块

> 本教程将指导你从零开始添加一个自定义方块。

---

## 概述

我们将添加一个名为 `dream_crystal` 的方块,具有以下特性:
- 基础方块,无特殊逻辑
- 需要镐子挖掘
- 掉落自身
- 有对应的物品形式

---

## 步骤 1: 创建方块类

### 1.1 创建方块类文件

创建文件 `PasterDream/src/main/java/com/pasterdream/pasterdreammod/block/DreamCrystalBlock.java`:

```java
package com.pasterdream.pasterdreammod.block;

import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.block.state.BlockBehaviour;

/**
 * 梦境水晶方块
 * 
 * 一种稀有的水晶方块,需要镐子挖掘。
 */
public class DreamCrystalBlock extends Block {
    public DreamCrystalBlock(BlockBehaviour.Properties properties) {
        super(properties);
    }
}
```

### 1.2 如果需要特殊逻辑

如果方块需要特殊逻辑 (如右键交互),可以覆写相应方法:

```java
@Override
protected InteractionResult useWithoutItem(BlockState state, Level level, BlockPos pos, Player player, BlockHitResult hitResult) {
    // 右键交互逻辑
    return InteractionResult.SUCCESS;
}
```

## 步骤 2: 注册方块

### 2.1 在 PDBlocks.java 中注册

打开 `PasterDream/src/main/java/com/pasterdream/pasterdreammod/registry/PDBlocks.java`,添加注册:

```java
// 在 PDBlocks 类中添加
public static final DeferredBlock<Block> DREAM_CRYSTAL = BlockAPI.REGISTRY.register("dream_crystal", 
    () -> new DreamCrystalBlock(
        BlockBehaviour.Properties.of()
            .mapColor(MapColor.COLOR_PURPLE)
            .requiresCorrectToolForDrops()
            .strength(5.0f, 6.0f)
            .sound(SoundType.AMETHYST)
            .lightLevel(state -> 15)));
```

### 2.2 注册方块物品

在同一文件中,注册对应的物品:

```java
// 在 PDItems 或 PDBlocks 中注册
BlockAPI.registerBlockItem(DREAM_CRYSTAL, CreativeModeTabs.BUILDING_BLOCKS);
```

## 步骤 3: 创建资源文件

### 3.1 方块状态 (Blockstate)

创建文件 `PasterDream/src/main/resources/assets/pasterdream/blockstates/dream_crystal.json`:

```json
{
    "variants": {
        "": {
            "model": "pasterdream:block/dream_crystal"
        }
    }
}
```

### 3.2 方块模型 (Block Model)

创建文件 `PasterDream/src/main/resources/assets/pasterdream/models/block/dream_crystal.json`:

```json
{
    "parent": "block/cube_all",
    "textures": {
        "all": "pasterdream:block/dream_crystal"
    }
}
```

### 3.3 物品模型 (Item Model)

创建文件 `PasterDream/src/main/resources/assets/pasterdream/models/item/dream_crystal.json`:

```json
{
    "parent": "pasterdream:block/dream_crystal"
}
```

### 3.4 纹理 (Texture)

创建纹理文件 `PasterDream/src/main/resources/assets/pasterdream/textures/block/dream_crystal.png`。

**注意**: 纹理需要是 16x16 像素的 PNG 文件。

## 步骤 4: 添加语言文件

### 4.1 英文

在 `PasterDream/src/main/resources/assets/pasterdream/lang/en_us.json` 中添加:

```json
{
    "block.pasterdream.dream_crystal": "Dream Crystal"
}
```

### 4.2 中文

在 `PasterDream/src/main/resources/assets/pasterdream/lang/zh_cn.json` 中添加:

```json
{
    "block.pasterdream.dream_crystal": "梦境水晶"
}
```

## 步骤 5: 添加战利品表

### 5.1 创建战利品表文件

创建文件 `PasterDream/src/main/resources/data/pasterdream/loot_table/blocks/dream_crystal.json`:

```json
{
    "type": "minecraft:block",
    "pools": [
        {
            "rolls": 1.0,
            "entries": [
                {
                    "type": "minecraft:item",
                    "name": "pasterdream:dream_crystal"
                }
            ],
            "conditions": [
                {
                    "condition": "minecraft:explosion_decay"
                }
            ]
        }
    ]
}
```
